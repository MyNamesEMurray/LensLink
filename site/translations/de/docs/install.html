Installation

Beide Hälften sind nötig: das Plugin in OBS, die App auf dem Smartphone. Nur die Schritte, die zu deiner Einrichtung passen, zeigt dir die Einrichtungsanleitung.

Voraussetzungen

  • OBS Studio 32 oder neuer (Hilfe → Über). Ältere Versionen laden das Plugin nicht.
  • iOS oder iPadOS 15 oder neuer.
  • Für USB: iTunes unter Windows (es liefert Apples Gerätetreiber) oder der Daemon usbmuxd unter Linux. macOS hat ihn bereits eingebaut, und für Wi-Fi ist nichts davon nötig.

Download-Seite

Das Plugin

Starte OBS nach jeder dieser Varianten neu. Unter Quellen → + sollten dann LensLink Camera und LensLink Screen erscheinen.

Windows

Führe LensLink-installer-windows-x64.exe aus. Es findet deinen OBS-Ordner und entfernt eine eventuell vorhandene Plugin-Version vor 1.0.

Manuelle Alternative: Entpacke lenslink-windows-x64.zip nach C:\Program Files\obs-studio\ und führe dabei die Ordner obs-plugins und data zusammen.

macOS

Öffne LensLink-installer-macos-universal.pkg. Das Paket ist nicht notarisiert, deshalb brauchst du beim ersten Mal Rechtsklick → Öffnen. Der Build ist universell – Apple Silicon und Intel.

Lieber aus der ZIP-Datei? Entpacke sie nach ~/Library/Application Support/obs-studio/plugins/ und entferne das Quarantäne-Attribut, sonst weigert sich OBS, das Plugin zu laden:

xattr -dr com.apple.quarantine \
  ~/Library/Application\ Support/obs-studio/plugins/lenslink.plugin

Linux

tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

Wenn das Plugin nicht erscheint und im Log libavcodec.so.60: cannot open shared object file steht, nutzt du eine Version vor 1.8, deren Tarball gegen das FFmpeg des Build-Rechners gelinkt war. Aktualisiere oder baue aus dem Quellcode.

Aus dem Quellcode

Vollständige Anleitung: obs-plugin/BUILDING.md. Auf einem System aus der Debian-Familie:

sudo apt install cmake build-essential pkg-config \
     libobs-dev libavcodec-dev libavutil-dev qt6-base-dev

cd obs-plugin
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

qt6-base-dev ist optional: Es fügt die Anzeige in der Statusleiste und das andockbare Panel hinzu. Alles andere lässt sich ohne Qt bauen.

Die App

App Store (empfohlen)

Installiere LensLink Camera aus dem App Store. Sie ist kostenlos, Updates kommen von selbst, und Siri-Befehle funktionieren.

TestFlight-Beta

Um neue Versionen zu bekommen, bevor sie im App Store sind, tritt unter testflight.apple.com/join/N7Rth6m3 bei. Jede Version erscheint zuerst in TestFlight, der App Store bekommt sie, sobald Apple das Update freigegeben hat.

Sideloading

Installiere LensLink-unsigned.ipa aus der neuesten Version mit Sideloadly oder einem ähnlichen Tool.

Auf diesem Weg gelten zwei Einschränkungen von Apple. Mit einer kostenlosen Apple-ID laufen per Sideloading installierte Apps nach 7 Tagen ab – installiere sie dann neu, die Einstellungen bleiben erhalten.

Beim erneuten Signieren wird außerdem die Bundle-ID geändert, wodurch die kompilierten Daten der Siri-Befehle verwaist sind: „Hey Siri, starte den Stream mit LensLink“ wird mit einer allgemeinen Absage beantwortet, obwohl dieselbe Aktion in der Kurzbefehle-App funktioniert. Nutze lenslink://start in einem Kurzbefehl oder installiere aus dem App Store.

Xcode

Es ist keine .xcodeproj eingecheckt, XcodeGen erzeugt sie.

brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

Hinweise zum Signieren und zu älteren Xcode-Versionen: ios-app/BUILDING.md.

Was sich je nach Betriebssystem unterscheidet

Die App, das Protokoll und alle Kamerafunktionen sind überall gleich, wo OBS läuft. Anders ist nur, wie das Plugin das Smartphone über USB erreicht und wie es dekodierte Frames auf die GPU bringt.

WindowsmacOSLinux
USB braucht iTunes, für den Apple Mobile Device Service Nichts – im Betriebssystem enthalten Den Daemon usbmuxd. Die meisten Desktop-Distributionen liefern ihn für den Zugriff auf Smartphones mit; installiere das Paket usbmuxd, wenn die Quelle kein Gerät meldet.
Hardware-Dekodierung D3D11VA, dann DXVA2 VideoToolbox VAAPI, dann VDPAU
GPU-Pipeline braucht Windows 10 1909+ macOS 13+ OBS mit EGL, dazu einen VAAPI-Treiber
10 Bit in der GPU-Pipeline Ja, als P010 Nein – VideoToolbox wandelt selbst in 8 Bit um, daher wird HDR über den Standardweg dargestellt Ja, als P010

Alles andere – Auflösungen, Codecs, HDR- und Apple-Log-Aufnahme, der Greenscreen, die Lippensynchronität, der Fernstart, das Browser-Steuerfeld – wird auf dem Smartphone oder in gemeinsamem Code entschieden und verhält sich auf allen dreien gleich.

Aktualisieren

Führe das neue Installationsprogramm des Plugins über dem alten aus und starte OBS neu. Die App wird über den App Store oder TestFlight aktualisiert oder durch eine Neuinstallation der neuen .ipa. Die beiden Hälften handeln eine Protokollversion aus, daher funktionieren eine etwas ältere App und ein neueres Plugin weiterhin zusammen. Falls eine Version jemals beide Seiten braucht, steht das in ihren Versionshinweisen.

Deinstallieren

  • Windows: Nutze den Deinstallationseintrag des Installationsprogramms oder lösche obs-plugins\64bit\lenslink.dll und data\obs-plugins\lenslink\.
  • macOS: Lösche ~/Library/Application Support/obs-studio/plugins/lenslink.plugin.
  • Linux: Lösche die entpackten Dateien aus ~/.config/obs-studio/plugins/.
  • App: Lösche sie wie gewohnt. Auf dem Computer bleibt nichts zurück.
