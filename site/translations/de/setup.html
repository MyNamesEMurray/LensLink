LensLink einrichten

Dein Computer
So verbindet sich das Smartphone

Nimm das Kabel – die Schritte unten sind die für USB. Wechsle zu WLAN, wenn das Smartphone an einem Ort stehen muss, den kein Kabel erreicht.

Was du in OBS haben möchtest
So installierst du die App

Unten stehen alle Schritte, jeweils markiert mit der Einrichtung, zu der sie gehören. Aktiviere JavaScript, um sie zu filtern.

  1. Prüfen, ob OBS Version 32 oder neuer ist

    Hilfe → Über.

  2. Plugin installieren Windows

    Führe LensLink-installer-windows-x64.exe von der Download-Seite aus.

  3. Plugin installieren macOS

    Öffne LensLink-installer-macos-universal.pkg von der Download-Seite mit Rechtsklick → Öffnen. Das Paket ist nicht notarisiert, deshalb wird ein Doppelklick abgelehnt.

  4. Plugin installieren Linux

    tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

  5. OBS neu starten

    Unter Quellen → + stehen jetzt LensLink Camera und LensLink Screen.

  6. App installieren App Store

    Installiere LensLink Camera aus dem App Store. Wenn du neue Versionen schon bekommen möchtest, bevor sie im App Store sind, tritt stattdessen der TestFlight-Beta bei.

  7. App installieren Sideloading

    LensLink-unsigned.ipa aus der neuesten Version, mit Sideloadly.

    Mit einer kostenlosen Apple-ID läuft sie nach 7 Tagen ab, und durch das erneute Signieren funktionieren die Siri-Befehle nicht mehr. Nutze lenslink://start in einem Kurzbefehl.

  8. App bauen Xcode

    brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

  9. iTunes installieren Windows USB

    Es liefert Apples Gerätetreiber. Ohne ihn erkennt USB das Smartphone nicht.

  10. Prüfen, ob usbmuxd installiert ist Linux USB

    Das Plugin verbindet sich mit /var/run/usbmuxd. Die meisten Desktop-Systeme bringen es mit, sonst installiere das Paket usbmuxd.

  11. Anschließen und auf „Vertrauen“ tippen USB

    Entsperre vorher das Smartphone und verwende ein Datenkabel.

  12. Beide Geräte ins selbe Netzwerk bringen WLAN

    Gastnetzwerke und Client-Isolation blockieren die Verbindung.

  13. LensLink auf dem Smartphone öffnen

    Wähle Objektiv, Auflösung, Bildrate und Codec.

    Der Einrichtungsbildschirm zeigt die Adresse an. Tippe darauf, um sie zu kopieren.

  14. Zugriff auf das lokale Netzwerk erlauben WLAN

    Nötig, damit das Smartphone mit Namen erscheint. Die IP-Adresse einzutippen funktioniert auch ohne.

  15. Quelle hinzufügen Kamera

    Quellen → + → LensLink Camera. Eine pro Smartphone.

  16. Quelle hinzufügen Bildschirm

    Quellen → + → LensLink Screen.

  17. Quelle auf das Smartphone richten USB

    Setze Verbindung auf USB-Kabel.

  18. Quelle auf das Smartphone richten WLAN

    Wähle es im Dropdown Telefon aus oder tippe die IP-Adresse ein.

  19. Kamera starten Kamera

    Tippe auf Kamera starten – oder lass die App einfach offen, dann startet OBS sie für dich.

  20. Übertragung starten Bildschirm

    Bildschirm spiegeln → LensLink Screen → Übertragung starten. Danach kannst du die App verlassen.

  21. Größe der Quelle festlegen Bildschirm

    Rechtsklick → Transformieren → Transformation bearbeiten …, dann Begrenzungstyp auf Anpassen setzen, damit ein App-Wechsel dein Layout nicht in der Größe verändert.

  22. Mikrofon abgleichen Kamera

    Optional: Wähle es unter Audioquelle für Lippensynchronität aus, aktiviere die Verzögerung und Automatisch kalibrieren, schalte in der App Automatische Lippensynchron-Referenz ein und sprich fünfzehn Sekunden lang. Details.
