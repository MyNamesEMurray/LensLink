Instalação

As duas metades são necessárias: o plugin no OBS e o app no celular. Para ver só os passos que correspondem à sua configuração, use o guia de configuração.

Requisitos

  • OBS Studio 32 ou mais recente (Ajuda → Sobre). Versões anteriores não carregam o plugin.
  • iOS ou iPadOS 15 ou posterior.
  • Para USB: o iTunes no Windows (ele fornece o driver de dispositivos da Apple) ou o daemon usbmuxd no Linux. O macOS já traz isso integrado, e o Wi-Fi não precisa de nada disso.

Página de downloads

O plugin

Reinicie o OBS depois de qualquer uma destas opções. Em seguida, Fontes → + deve oferecer LensLink Camera e LensLink Screen.

Windows

Execute o LensLink-installer-windows-x64.exe. Ele encontra a pasta do OBS e remove qualquer cópia do plugin anterior à versão 1.0.

Alternativa manual: descompacte o lenslink-windows-x64.zip em C:\Program Files\obs-studio\, mesclando as pastas obs-plugins e data.

macOS

Abra o LensLink-installer-macos-universal.pkg. O pacote não é notarizado, então na primeira vez você precisa usar clique com o botão direito → Abrir. A versão é universal: Apple silicon e Intel.

Prefere o zip? Extraia em ~/Library/Application Support/obs-studio/plugins/ e remova o atributo de quarentena, senão o OBS se recusa a carregá-lo:

xattr -dr com.apple.quarantine \
  ~/Library/Application\ Support/obs-studio/plugins/lenslink.plugin

Linux

tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

Se o plugin não aparecer e o log disser libavcodec.so.60: cannot open shared object file, você está com uma versão anterior à 1.8, cujo tarball estava vinculado ao FFmpeg da máquina de compilação. Atualize ou compile a partir do código-fonte.

A partir do código-fonte

Instruções completas: obs-plugin/BUILDING.md. Em um sistema da família Debian:

sudo apt install cmake build-essential pkg-config \
     libobs-dev libavcodec-dev libavutil-dev qt6-base-dev

cd obs-plugin
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

O qt6-base-dev é opcional: ele adiciona os indicadores na barra de status e o painel encaixável. Todo o resto compila sem o Qt.

O app

App Store (recomendado)

Instale o LensLink Camera pela App Store. Ele é gratuito, as atualizações chegam sozinhas e as frases da Siri funcionam.

Beta no TestFlight

Para receber novas versões antes que cheguem à App Store, participe em testflight.apple.com/join/N7Rth6m3. Toda versão sai primeiro no TestFlight; a App Store a recebe assim que a Apple aprova a atualização.

Sideload

Instale o LensLink-unsigned.ipa da versão mais recente com o Sideloadly ou uma ferramenta parecida.

Este caminho vem com duas limitações da Apple. Com uma Conta Apple gratuita, apps instalados por sideload expiram depois de 7 dias: reinstale para renovar; os ajustes são mantidos.

A nova assinatura também reescreve o ID do pacote, o que deixa órfãos os dados compilados das frases da Siri: "E aí Siri, comece a transmitir com o LensLink" recebe uma recusa genérica, mesmo que a mesma ação funcione pelo app Atalhos. Use lenslink://start em um atalho ou instale pela App Store.

Xcode

Nenhum .xcodeproj está no repositório; o XcodeGen o gera.

brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

Notas sobre assinatura e versões antigas do Xcode: ios-app/BUILDING.md.

O que muda em cada sistema operacional

O app, o protocolo e todos os recursos da câmera são idênticos em qualquer sistema onde o OBS rode. O que muda é como o plugin alcança o celular via USB e como ele leva os quadros decodificados para a GPU.

WindowsmacOSLinux
O USB precisa de iTunes, para o Apple Mobile Device Service Nada: já vem integrado ao sistema O daemon usbmuxd. A maioria das distribuições desktop já o traz para acessar celulares; instale o pacote usbmuxd se a fonte informar que não há dispositivo.
Decodificação por hardware D3D11VA, depois DXVA2 VideoToolbox VAAPI, depois VDPAU
O pipeline na GPU precisa de Windows 10 1909+ macOS 13+ OBS em EGL, mais um driver VAAPI
10 bits no pipeline na GPU Sim, como P010 Não: o VideoToolbox converte para 8 bits por conta própria, então o HDR é renderizado pelo caminho padrão Sim, como P010

Todo o resto (resoluções, codecs, captura em HDR e Apple Log, a tela verde, sincronia labial, início remoto, o painel no navegador) é decidido no celular ou em código compartilhado, e se comporta igual nos três.

Atualização

Execute o novo instalador do plugin por cima do antigo e reinicie o OBS; o app se atualiza pela App Store ou pelo TestFlight, ou reinstalando o novo .ipa. As duas metades negociam uma versão do protocolo, então um app um pouco mais antigo e um plugin mais novo continuam funcionando juntos. Se uma versão exigir atualizar os dois lados, as notas dela avisam.

Desinstalação

  • Windows: a opção de desinstalar do instalador, ou apague obs-plugins\64bit\lenslink.dll e data\obs-plugins\lenslink\.
  • macOS: apague ~/Library/Application Support/obs-studio/plugins/lenslink.plugin.
  • Linux: apague os arquivos extraídos de ~/.config/obs-studio/plugins/.
  • App: apague-o como de costume. Nada fica no computador.
