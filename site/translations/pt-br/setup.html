Configurar o LensLink

Seu computador
Como o celular se conecta

Use o cabo: os passos abaixo são os de USB. Mude para Wi-Fi se o celular precisar ficar em um lugar aonde o cabo não chega.

O que você quer no OBS
Como você vai instalar o app

Todos os passos aparecem abaixo, marcados com a configuração a que pertencem. Ative o JavaScript para filtrá-los.

  1. Confira se o OBS é a versão 32 ou mais recente

    Ajuda → Sobre.

  2. Instale o plugin Windows

    Execute o LensLink-installer-windows-x64.exe da página de downloads.

  3. Instale o plugin macOS

    Abra o LensLink-installer-macos-universal.pkg da página de downloads com clique com o botão direito → Abrir. Ele não é notarizado, então o clique duplo é recusado.

  4. Instale o plugin Linux

    tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

  5. Reinicie o OBS

    Fontes → + agora lista LensLink Camera e LensLink Screen.

  6. Instale o app App Store

    Instale o LensLink Camera pela App Store. Para receber novas versões antes que cheguem à App Store, participe do beta no TestFlight.

  7. Instale o app Sideload

    LensLink-unsigned.ipa da versão mais recente, pelo Sideloadly.

    Com uma Conta Apple gratuita, ele expira depois de 7 dias, e a nova assinatura faz as frases da Siri pararem de funcionar: use lenslink://start em um atalho.

  8. Compile o app Xcode

    brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

  9. Instale o iTunes Windows USB

    Ele fornece o driver de dispositivos da Apple. Sem ele, o USB não enxerga o celular.

  10. Confira se o usbmuxd está instalado Linux USB

    O plugin se conecta a /var/run/usbmuxd. A maioria dos ambientes de desktop já o traz; se não for o caso, instale o pacote usbmuxd.

  11. Conecte o cabo e toque em Confiar USB

    Desbloqueie o celular antes e use um cabo de dados.

  12. Coloque os dois na mesma rede Wi-Fi

    Redes de convidados e o isolamento de clientes bloqueiam a conexão.

  13. Abra o LensLink no celular

    Escolha lente, resolução, taxa de quadros e codec.

    A tela de configuração mostra o endereço do celular: toque para copiar.

  14. Permita o acesso à Rede Local Wi-Fi

    Necessário para o celular aparecer pelo nome. Digitar o IP funciona sem essa permissão.

  15. Adicione a fonte Câmera

    Fontes → + → LensLink Camera. Uma por celular.

  16. Adicione a fonte Tela

    Fontes → + → LensLink Screen.

  17. Aponte a fonte para o celular USB

    Defina Conexão como Cabo USB.

  18. Aponte a fonte para o celular Wi-Fi

    Escolha o celular na lista Celular ou digite o IP.

  19. Inicie a câmera Câmera

    Toque em Iniciar câmera, ou deixe o app aberto e o OBS a inicia para você.

  20. Inicie a transmissão Tela

    Espelhar tela → LensLink Screen → Iniciar Transmissão. Depois disso, você pode sair do app.

  21. Fixe o tamanho da fonte Tela

    Clique com o botão direito → Transformar → Editar transformação..., defina Tipo de limites como Ajustar, para que trocar de app não redimensione o seu layout.

  22. Alinhe o seu microfone Câmera

    Opcional: escolha-o em Fonte de áudio para sincronia labial, ative o atraso e Calibrar automaticamente, ligue a Referência automática de sincronia labial no app e fale por quinze segundos. Detalhes.
