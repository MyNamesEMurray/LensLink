Descargar LensLink

Dos mitades que se comunican entre sí: un plugin para OBS Studio y una app en tu iPhone o iPad. Necesitas las dos.

Antes de instalar

Las dos cosas que más problemas dan.

OBS Studio 32 o posterior Ayuda → Acerca de. Las versiones anteriores no cargan el plugin.
Software de apoyo para USB, solo si usas USB El controlador de dispositivos de Apple viene con iTunes. Linux necesita en su lugar el daemon usbmuxd; macOS lo trae integrado. Por Wi-Fi no hace falta ninguno.
