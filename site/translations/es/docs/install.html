Instalación

Hacen falta las dos mitades: el plugin en OBS y la app en el teléfono. Si solo quieres los pasos que corresponden a tu configuración, usa la guía de configuración.

Requisitos

  • OBS Studio 32 o posterior (Ayuda → Acerca de). Las versiones anteriores no cargan el plugin.
  • iOS o iPadOS 15 o posterior.
  • Para USB: iTunes en Windows (incluye el controlador de dispositivos de Apple) o el daemon usbmuxd en Linux. macOS lo trae integrado, y por Wi-Fi no hace falta nada de esto.

Página de descarga

El plugin

Después de cualquiera de estas opciones, reinicia OBS. Fuentes → + debería ofrecer entonces LensLink Camera y LensLink Screen.

Windows

Ejecuta LensLink-installer-windows-x64.exe. Localiza tu carpeta de OBS y elimina cualquier copia del plugin anterior a la 1.0.

Alternativa manual: descomprime lenslink-windows-x64.zip en C:\Program Files\obs-studio\, combinando las carpetas obs-plugins y data.

macOS

Abre LensLink-installer-macos-universal.pkg. El paquete no está notarizado, así que la primera vez tienes que usar clic derecho → Abrir. La compilación es universal: Apple silicon e Intel.

¿Prefieres el zip? Extráelo en ~/Library/Application Support/obs-studio/plugins/ y quita el atributo de cuarentena, o OBS se negará a cargarlo:

xattr -dr com.apple.quarantine \
  ~/Library/Application\ Support/obs-studio/plugins/lenslink.plugin

Linux

tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

Si el plugin no aparece y el registro dice libavcodec.so.60: cannot open shared object file, tienes una versión anterior a la 1.8, cuyo tarball enlazaba el FFmpeg de la máquina de compilación. Actualiza o compila desde el código fuente.

Desde el código fuente

Instrucciones completas: obs-plugin/BUILDING.md. En un sistema de la familia Debian:

sudo apt install cmake build-essential pkg-config \
     libobs-dev libavcodec-dev libavutil-dev qt6-base-dev

cd obs-plugin
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

qt6-base-dev es opcional: añade la lectura en la barra de estado y el panel acoplable. Todo lo demás se compila sin Qt.

La app

App Store (recomendado)

Instala LensLink Camera desde el App Store. Es gratis, las actualizaciones llegan solas y las frases de Siri funcionan.

Beta de TestFlight

Para recibir las nuevas versiones antes de que lleguen al App Store, únete en testflight.apple.com/join/N7Rth6m3. Cada versión llega primero a TestFlight; el App Store la recibe cuando Apple aprueba la actualización.

Instalación manual (sideload)

Instala LensLink-unsigned.ipa de la última versión con Sideloadly o una herramienta similar.

Esta vía tiene dos limitaciones de Apple. Con un Apple ID gratuito, las apps instaladas manualmente caducan a los 7 días: vuelve a instalarla para renovarla; los ajustes se conservan.

Además, al volver a firmarla se reescribe el identificador del paquete (bundle ID), lo que deja huérfanos los datos compilados de las frases de Siri: “Oye Siri, empieza a transmitir con LensLink” recibe una negativa genérica, aunque la misma acción funciona desde Atajos. Usa lenslink://start en un atajo o instala la app desde el App Store.

Xcode

No hay ningún .xcodeproj en el repositorio; lo genera XcodeGen.

brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

Notas sobre la firma y sobre versiones anteriores de Xcode: ios-app/BUILDING.md.

Qué cambia según el sistema operativo

La app, el protocolo y todas las funciones de cámara son idénticos en cualquier sistema donde funcione OBS. Lo que cambia es cómo llega el plugin al teléfono por USB y cómo lleva los fotogramas decodificados a la GPU.

Actualizar

Ejecuta el nuevo instalador del plugin sobre el anterior y reinicia OBS; la app se actualiza a través del App Store o de TestFlight, o volviendo a instalar el nuevo .ipa. Las dos mitades negocian una versión del protocolo, así que una app un poco más antigua y un plugin más nuevo siguen funcionando juntos; si alguna versión necesita actualizar ambos lados, sus notas lo indican.

Desinstalar

  • Windows: usa la entrada de desinstalación del instalador, o elimina obs-plugins\64bit\lenslink.dll y data\obs-plugins\lenslink\.
  • macOS: elimina ~/Library/Application Support/obs-studio/plugins/lenslink.plugin.
  • Linux: elimina los archivos extraídos de ~/.config/obs-studio/plugins/.
  • App: elimínala como cualquier otra. No queda nada en la computadora.
