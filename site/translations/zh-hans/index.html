你的 iPhone 已经是你最好的摄像头。把它接进 OBS。

两个 OBS 来源（一个摄像头，一个屏幕镜像），通过 Wi-Fi 或 USB 直接连接你的 iPhone 或 iPad。不需要虚拟摄像头驱动，不需要 RTMP 服务器，也不需要订阅。

设置

三个步骤，大约三分钟

电脑上装插件，手机上装 App，OBS 里加来源。无需配置路由器，无需账户。

  1. 安装 OBS 插件

    Windows 和 macOS 有安装程序，Linux 有 tar 压缩包。它会在你现有的 OBS 中添加两个来源。

  2. 安装 iPhone App

    在 App Store 免费下载。你也可以加入 TestFlight 测试版、侧载未签名版本，或自行编译。

  3. 在 OBS 中添加来源

    源 → + → LensLink Camera，然后选择你的手机或插上数据线。一两秒内就会出现画面。

改为回答四个问题 完整安装指南

你能得到什么

真正的摄像头来源，而不是网络摄像头的变通方案

手机用硬件编码，插件在你的 GPU 上解码，再把帧交给 OBS。只有一条连接，中间没有任何环节。

最高 4K 60 fps

H.264 或 HEVC。选择器只提供你的摄像头实际支持的组合。

Wi-Fi 或 USB

USB 不需要网络，延迟最稳定，还能边推流边给手机充电。Wi-Fi 则省掉了线缆。

在电脑上控制

变焦、曝光、手动 ISO 和快门、对焦、白平衡、手电筒、镜头、切换摄像头，可以在手机、浏览器面板或来源设置中操作。

自动音画同步

插件测量真实延迟，并将你自己的麦克风与画面对齐。大约十五秒后稳定下来，之后保持不变。

屏幕镜像

第二种来源类型通过 iOS 自带的屏幕直播镜像整个屏幕及其音频。适合手机游戏和 App 演示。

远程启动

由 OBS 自己启动摄像头，架好的手机无需取下。Siri 和快捷指令也可以。

更进一步

网络摄像头做不到的事

全部需要手动开启。不做任何改动时，此来源就是一个普通的 SDR 摄像头。

Apple Log（测试版）

在 Pro 系列 iPhone（iOS 17+）上，推送平坦的 10 位 Log 画面，并用 OBS 的“应用 LUT”滤镜调色。插件如实解码，此外不对画面做任何处理。

HLG 格式的 HDR（测试版）

在支持的摄像头上，通过 HEVC 传输 10 位 HLG。无论 SDR 还是 HDR 画布，OBS 都能正确渲染。

虚拟绿幕（测试版）

手机在编码前把你以外的一切涂成纯绿色，插件则添加一个调校好的色度键滤镜。借助 Face ID 或 LiDAR 深度，距离截断会去掉从你身后走过的人。

所有镜头，实时切换

主摄、超广角、长焦、前置，推流过程中切换，OBS 来源不会中断。

GPU 解码管线（测试版）

解码后的视频留在显卡上，而不是在系统内存中来回传输。CPU 占用和延迟都更低，4K 下尤为明显。

看得见的健康状态

解码帧率、传输码率和实测延迟，按手机逐秒显示在 OBS 的状态栏和一个可停靠的面板中。

规格

视频最高 3840×2160、60 fps，H.264 或 HEVC。HDR（HLG）和 Apple Log 为测试版。
延迟通过 USB，1080p 或 4K 下约 60 ms。Wi-Fi 更高，波动也更大。
传输USB 或本地 Wi-Fi。一条 TCP 连接，没有云端中转。
音频可选：手机麦克风作为来源的音频、作为音画同步的时间参考，或在屏幕镜像时传输系统音频。
电脑Windows、macOS 或 Linux 上的 OBS Studio 32+。在 Windows 上使用 USB 需要 iTunes 提供 Apple 的驱动程序。
手机运行 iOS/iPadOS 15+ 的 iPhone 或 iPad。
摄像头可同时使用多台：每部手机一个来源，各自独立控制。
价格免费，GPL-2.0-or-later。无需账户，没有水印，没有付费升级版。
