安装

两部分缺一不可：OBS 中的插件，手机上的 App。如果只想看与你的配置相符的步骤，可以使用设置向导。

系统要求

  • OBS Studio 32 或更高版本（帮助 → 关于）。更早的版本无法加载插件。
  • iOS 或 iPadOS 15 或更高版本。
  • 使用 USB 时：Windows 上需要 iTunes（它提供 Apple 的设备驱动程序），Linux 上需要 usbmuxd 守护进程。macOS 已内置，使用 Wi-Fi 则都不需要。

下载页面

插件

无论用以下哪种方式安装，之后都要重启 OBS。然后 源 → + 中应该会出现 LensLink Camera 和 LensLink Screen。

Windows

运行 LensLink-installer-windows-x64.exe。它会找到你的 OBS 文件夹，并移除任何 1.0 之前版本的插件副本。

手动安装：将 lenslink-windows-x64.zip 解压到 C:\Program Files\obs-studio\，合并 obs-plugins 和 data 文件夹。

macOS

打开 LensLink-installer-macos-universal.pkg。该安装包未经公证，所以第一次需要右键点按 → 打开。这是通用版本，同时支持 Apple 芯片和 Intel。

如果改用 zip 包：解压到 ~/Library/Application Support/obs-studio/plugins/，并清除隔离标记，否则 OBS 会拒绝加载它：

xattr -dr com.apple.quarantine \
  ~/Library/Application\ Support/obs-studio/plugins/lenslink.plugin

Linux

tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

如果插件没有出现，且日志中显示 libavcodec.so.60: cannot open shared object file，说明你使用的是 1.8 之前的版本，它的压缩包链接了构建机器上的 FFmpeg。更新版本，或从源代码构建。

从源代码构建

完整说明： obs-plugin/BUILDING.md。 在 Debian 系的系统上：

sudo apt install cmake build-essential pkg-config \
     libobs-dev libavcodec-dev libavutil-dev qt6-base-dev

cd obs-plugin
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

qt6-base-dev 是可选的：它提供状态栏读数和可停靠的面板。其他部分不需要 Qt 也能构建。

App

App Store（推荐）

从 App Store 安装 LensLink Camera。它是免费的，会自动更新，而且 Siri 短语可以正常使用。

TestFlight 测试版

如果想在新版本上架 App Store 之前抢先使用，可以通过 testflight.apple.com/join/N7Rth6m3 加入。每个版本都会先发布到 TestFlight；Apple 批准更新后，App Store 才会收到它。

侧载

使用 Sideloadly 或类似工具，安装最新版本中的 LensLink-unsigned.ipa。

这种方式会带来 Apple 的两项限制。使用免费 Apple ID 时，侧载的 App 会在 7 天后过期。重新安装即可续期，设置会保留。

重新签名还会改写 bundle ID，导致编译好的 Siri 短语数据失效：“嘿 Siri，用 LensLink 开始推流”会得到一个笼统的拒绝，尽管同一操作在快捷指令中可以正常运行。可以在快捷指令中使用 lenslink://start，或从 App Store 安装。

Xcode

仓库中没有提交 .xcodeproj，它由 XcodeGen 生成。

brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

签名以及旧版 Xcode 的相关说明： ios-app/BUILDING.md。

各操作系统的差异

无论 OBS 运行在哪里，App、协议和每一项摄像头功能都完全相同。不同的是插件如何通过 USB 连接手机，以及如何把解码后的帧送到 GPU 上。

WindowsmacOSLinux
USB 需要 iTunes，用于 Apple Mobile Device Service 无需额外安装，系统已内置 usbmuxd 守护进程。大多数桌面发行版为了访问手机都会自带它；如果来源提示没有设备，安装 usbmuxd 软件包。
硬件解码 D3D11VA，其次是 DXVA2 VideoToolbox VAAPI，其次是 VDPAU
GPU 管线需要 Windows 10 1909+ macOS 13+ 基于 EGL 的 OBS，以及 VAAPI 驱动程序
GPU 管线上的 10 位 支持，格式为 P010 不支持：VideoToolbox 会自行转换为 8 位，因此 HDR 通过标准路径渲染 支持，格式为 P010

其他一切，包括分辨率、编码格式、HDR 和 Apple Log 采集、绿幕、音画同步、远程启动、浏览器面板，都由手机或共享代码决定，在三个平台上表现一致。

更新

在旧版本上直接运行新的插件安装程序，然后重启 OBS；App 通过 App Store 或 TestFlight 更新，或重新安装新的 .ipa。 两部分会协商协议版本，所以稍旧的 App 搭配较新的插件仍能正常工作。如果某个版本需要两端同时更新，其发行说明中会注明。

卸载

  • Windows：使用安装程序的卸载项，或删除 obs-plugins\64bit\lenslink.dll 和 data\obs-plugins\lenslink\。
  • macOS：删除 ~/Library/Application Support/obs-studio/plugins/lenslink.plugin。
  • Linux：从 ~/.config/obs-studio/plugins/ 中删除解压出的文件。
  • App：像平常一样删除即可。电脑上不会留下任何内容。
