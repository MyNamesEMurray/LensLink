将 OBS 连接到手机

一条 TCP 连接承载视频、摄像头控制、时钟同步和状态信息，经由你的本地网络或 USB 线传输。不经过互联网。

简要步骤

  1. 在手机上

    打开 LensLink，选择摄像头和格式，然后轻点启动摄像头。主界面会显示手机的 Wi-Fi 地址，轻点即可复制。

    如果从 OBS 远程启动处于打开状态（默认），只要让 App 保持打开并处于空闲状态即可，OBS 会自己启动摄像头。

  2. 在 OBS 中

    源 → + → LensLink Camera。每部手机一个来源。

  3. 让来源指向手机

    Wi-Fi：在手机下拉菜单中选择你的设备，或输入 App 显示的 IP。

    USB：插上数据线，并将连接设为 USB 线。

一两秒内就会出现画面。推流过程中离开 App 会让来源变为空白，因为 iOS 会暂停不在屏幕上的 App 的摄像头采集。在支持的 iPad 上，LensLink 在分屏浏览、侧拉和台前调度中与其他 App 并排显示时仍会继续推流。

Wi-Fi

两台设备必须位于同一网络，而且该网络必须允许设备之间直接通信。访客网络、启用了客户端隔离的接入点，以及许多办公室或校园网络都会阻止这种通信；而电脑连接到手机开启的热点则不会。

按名称查找手机

App 打开时会通过 Bonjour 广播自己，手机下拉菜单会列出找到的设备。如果列表中没有你的手机，但输入 IP 可以连接，说明 App 缺少 iOS 进行这种广播所需的本地网络权限：在系统询问时允许，或前往设置 → 隐私与安全性 → 本地网络 → LensLink 中开启。

手机也会获取新的 DHCP 租约，这是按名称选择的另一个原因。如果你更喜欢输入地址，可以在路由器中为手机保留一个地址。

USB

凡是重要的场合都用 USB：不涉及网络，延迟最稳定，而且手机在编码时还能充电。这一点很有价值，因为编码视频是手机要做的最繁重的工作之一。

  1. 仅限 Windows：安装 iTunes

    它提供 Apple 的设备驱动程序。没有它，任何数据线都无法使用。

  2. 插上数据线并轻点“信任”

    手机必须处于解锁状态才会弹出提示，而且必须使用数据线。

  3. 将“连接”设为“USB 线”

    除非你使用多部手机，否则将 USB 设备保持为自动。

插了多部手机时，将每个来源的 USB 设备设为特定设备，而不是“自动”。这样无论插入顺序如何，同一部手机都始终为同一个来源供流。固定到未连接设备的来源会等待，并显示相应提示。

同时使用多部手机

每部手机一个 LensLink Camera 来源。每个来源都有自己的连接、控件和健康状态读数，浏览器面板也会为每个来源增加一个标签页。

一部手机同一时间只能为一个来源供流。第二个指向同一设备的来源会提示该设备已被占用。例外：开启此来源未在任何位置显示时断开连接后，隐藏的来源会释放手机，因此一个场景中的 Camera 来源和另一个场景中的 Screen 来源可以共用同一部手机。

读懂“状态”字段

每个 LensLink 来源的设置顶部都有一行状态，它会指出具体是哪个环节出了问题。

状态含义
已连接：…正在推流。附带设备、格式和实测延迟。
已连接，摄像头空闲待机：App 可访问，但未在采集。可以在这里、在浏览器面板中或在手机上启动它。
正在启动手机摄像头…已发送远程启动指令，摄像头正在启动。
正在尝试连接手机 …地址错误或无法访问，或者 App 不在前台。
输入手机的 IP 地址Wi-Fi 来源未设置主机地址。
未在 USB 上检测到设备检查数据线并轻点“信任”。在 Windows 上，确认已安装 iTunes。
已找到设备，但无法连接到 LensLink App数据线没有问题。解锁手机，并将 App 切换到前台。
正在等待所选 USB 设备固定到了一台未连接的设备。
此设备已被另一个 LensLink 来源占用两个来源，一部手机。见上文。
已断开，正在重新连接连接中断，来源正在重新拨号。
已暂停：来源已隐藏此来源未在任何位置显示时断开连接已开启，且没有任何地方显示该来源。
手机正在发送屏幕直播来源类型错误。屏幕直播要用 LensLink Screen 来源。
已连接，但此 OBS 版本无法解码该视频流该版本中没有 HEVC 解码器。将 App 切换为 H.264。

保持良好状态

  • 留意数字。OBS 的状态栏为每部手机显示一行，如 LensLink: iPhone 60 fps · 11.9 Mb/s · 43 ms；视图 → 停靠窗口 → LensLink 则以面板形式显示同样的内容。
  • 网络拥塞会自动处理。App 会短暂降低画质再恢复，而不是让延迟不断累积。
  • 节省电量：开启此来源未在任何位置显示时断开连接后，只要来源被隐藏，手机就会停止编码。
  • 视频流在你的网络中不加密，适用于可信的家庭和工作室网络。

如果无法连接

  1. App 是否显示在屏幕上，且手机已解锁？
  2. Wi-Fi：是否在同一网络，而不是有一台设备连着访客 SSID？
  3. USB：是否使用数据线，并已轻点信任？
  4. 否则，按照上表中与你的“状态”字段相符的那一行处理。

仍然无法解决：故障排除。
