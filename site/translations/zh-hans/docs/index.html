文档

两个相互通信的程序：OBS 中的插件，手机上的 App。这些页面介绍如何安装两者、如何连接它们，以及两者提供的每一项设置。

赶时间？设置向导会问你四个问题，只给出与你的回答相符的步骤。你也可以先读安装，再读连接，内容相同，只是更完整。

各部分如何配合

App 负责采集，用硬件编码为 H.264 或 HEVC，并在 TCP 端口 9979 上等待连接。插件通过你的网络或 Apple 的 USB 设备服务连接该端口，尽可能在 GPU 上解码，再把帧作为普通来源交给 OBS。

没有云服务，无需账户。只要两端能互相访问，LensLink 就能工作。

组件运行位置作用
LensLink AppiPhone / iPad采集、编码、等待连接。在屏幕上显示时推流（在支持的 iPad 上，与其他 App 并排显示时也可以）。
LensLink CameraOBS 来源摄像头视频流、它的控件，以及音画同步。
LensLink ScreenOBS 来源iOS 屏幕直播及其系统音频。
浏览器面板http://localhost:9980同样的摄像头控件，在电脑上使用。

从这里开始

  • 安装Windows、macOS 和 Linux 上的插件；通过 App Store、TestFlight、侧载或 Xcode 安装 App。
  • 将 OBS 连接到手机Wi-Fi、USB、多部手机，以及每条状态信息的含义。
  • 摄像头、镜头与画面格式、手动曝光、HDR、Apple Log、绿幕、记住的设置。
  • 屏幕镜像屏幕直播、屏幕音频，以及固定来源尺寸。
  • 音频与音画同步把手机用作麦克风，以及自动对齐你自己的麦克风。
  • 远程启动通过 OBS、Siri、快捷指令或 URL 启动摄像头。
  • 浏览器控制面板端口 9980 上的面板及其背后的 HTTP API。
  • 设置参考每一项来源属性、插件设置和 App 选项。
  • 延迟与性能延迟由哪些部分构成，以及 GPU 解码管线。
  • 故障排除按症状逐一说明，并附上需要查找的日志行。

术语

以下每个术语在 App、插件和这些页面中都只表示一个特定的含义。

主界面App 的第一个界面：电脑卡片、摄像头各行和两个“启动”按钮，此时还没有开始推流。
直播界面推流时的全屏视图：画面、镜头按钮，以及轻点一下即可打开的调节栏。
待机App 已打开且处于空闲状态，OBS 已连接并可以启动摄像头。琥珀色。
Tally 灯彩色边框，表示来源在 OBS 中的状态：播出中、预览中，以及你选择的其他状态。
空闲显示你最后一次触摸 10 秒后，直播界面所变成的样子。
音画同步参考仅作为时间信号发送的手机麦克风音频。永远不会在直播中被听到。
