手机的连接方式

用数据线，下面列出的就是 USB 的步骤。如果手机必须放在线缆够不到的地方， 再切换到 Wi-Fi。

你打算如何安装 App

下面列出了所有步骤，并标注了各自适用的设置。开启 JavaScript 即可筛选。

  1. 确认 OBS 为 32 或更高版本

    帮助 → 关于。

  2. 安装插件 Windows

    运行下载页面中的 LensLink-installer-windows-x64.exe。

  3. 安装插件 macOS

    用右键点按 → 打开来打开下载页面中的 LensLink-installer-macos-universal.pkg。它未经公证，所以双击打开会被拒绝。

  4. 安装插件 Linux

    tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

  5. 重启 OBS

    源 → + 中现在会列出 LensLink Camera 和 LensLink Screen。

  6. 安装 App App Store

    从 App Store 安装 LensLink Camera。如果想在新版本上架 App Store 之前抢先使用，可以改为加入 TestFlight 测试版。

  7. 安装 App 侧载

    从最新版本下载 LensLink-unsigned.ipa，通过 Sideloadly 安装。

    使用免费 Apple ID 时，它会在 7 天后过期，而且重新签名会让 Siri 短语失效。可改为在快捷指令中使用 lenslink://start。

  8. 构建 App Xcode

    brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

  9. 安装 iTunes Windows USB

    它提供 Apple 的设备驱动程序。没有它，USB 就无法识别手机。

  10. 确认已安装 usbmuxd Linux USB

    插件会连接到 /var/run/usbmuxd。大多数桌面系统都自带它；如果没有，安装 usbmuxd 软件包即可。

  11. 插上数据线并轻点“信任” USB

    先解锁手机，并使用数据线。

  12. 让两台设备连接同一网络 Wi-Fi

    访客网络和客户端隔离会阻止连接。

  13. 在手机上打开 LensLink

    选择镜头、分辨率、帧率和编码格式。

    主界面会显示手机的地址，轻点即可复制。

  14. 允许“本地网络”权限 Wi-Fi

    手机要按名称出现在列表中，就需要这项权限。不开启也可以直接输入 IP。

  15. 添加来源 摄像头

    源 → + → LensLink Camera。每部手机一个。

  16. 添加来源 屏幕

    源 → + → LensLink Screen。

  17. 让来源指向手机 USB

    将连接设为 USB 线。

  18. 让来源指向手机 Wi-Fi

    在手机下拉菜单中选择它，或输入 IP。

  19. 启动摄像头 摄像头

    轻点启动摄像头，或者让 App 保持打开，由 OBS 替你启动。

  20. 开始屏幕直播 屏幕

    镜像屏幕 → LensLink Screen → 开始直播。之后你可以离开 App。

  21. 固定来源尺寸 屏幕

    右键点击 → 变换 → 编辑变换…，将边框类型设为等比缩放到框内，这样切换 App 时就不会改变你的布局尺寸。

  22. 对齐你的麦克风 摄像头

    可选：在音画同步音频来源中选择它，启用延迟和自动校准，在 App 中打开自动音画同步参考，然后说话十五秒。详情。
