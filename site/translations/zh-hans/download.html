下载 LensLink

相互通信的两部分：OBS Studio 的插件，以及你的 iPhone 或 iPad 上的 App。两者缺一不可。

第 1 部分

OBS 插件

为 OBS Studio 32+ 添加 LensLink Camera 和 LensLink Screen 来源。安装后需重启 OBS。

  • Windows 安装程序 LensLink-installer-windows-x64.exe 下载
  • Windows，手动安装 lenslink-windows-x64.zip 下载
  • macOS 安装包 LensLink-installer-macos-universal.pkg 下载
  • macOS，手动安装 lenslink-macos-universal.zip 下载
  • Linux lenslink-linux-x86_64.tar.gz 下载

各平台的步骤：安装指南。 也可以从源代码构建。

第 2 部分

iPhone / iPad App

负责采集视频并等待 OBS 连接。需要 iOS 或 iPadOS 15+。在 App Store 免费下载，并会自动更新。

在 App Store 获取

LensLink Camera，免费，无 App 内购买项目。

  • TestFlight 测试版 在 App 审核之前抢先体验新版本 加入
  • 侧载，未签名版本 LensLink-unsigned.ipa 下载
  • 在 Xcode 中构建 ios-app/BUILDING.md 说明

使用免费 Apple ID 时，侧载的 App 会在 7 天后过期，并且 Siri 短语会失效。原因。

安装之前

最容易让人卡住的两件事。

OBS Studio 32 或更高版本 帮助 → 关于。更早的版本无法加载插件。
USB 辅助组件，仅限 USB Apple 的设备驱动程序随 iTunes 一起提供。Linux 则需要 usbmuxd 守护进程；macOS 已内置。使用 Wi-Fi 时都不需要。
