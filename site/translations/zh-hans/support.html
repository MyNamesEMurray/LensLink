支持

LensLink 免费且开源，支持渠道就在代码所在的地方。大多数问题在文档中都能找到答案，其余的可以到 GitHub 提出。

从这里开始

  • 设置向导：回答四个问题，获取与你的电脑和连接方式完全对应的步骤。
  • 通过 Wi-Fi 或 USB 将手机连接到 OBS。
  • 故障排除：没有画面、来源卡住、音画不同步等问题。
  • 常见问题。
  • 文档中的其他所有内容。

报告错误或提出功能建议

在 GitHub 上提交 issue： github.com/MyNamesEMurray/LensLink/issues。 写明你的 App 版本和 iPhone 或 iPad 型号、OBS 和插件的版本，以及你使用的是 Wi-Fi 还是 USB。App 的选项界面中有一份摄像头诊断报告，可以直接粘贴进来；插件的“工具 → LensLink 设置”中有复制诊断报告。

发行说明与下载

插件和 App 的每个版本都列在版本发布页面上，并附有各版本的更改内容。下载页面始终指向最新版本。

隐私

App 不收集任何数据。隐私政策说明了它能看到什么以及原因。
