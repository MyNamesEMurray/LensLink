Installer

Les deux moitiés sont nécessaires : le plugin dans OBS, l’app sur le téléphone. Pour n’obtenir que les étapes qui correspondent à votre configuration, utilisez le guide de configuration.

Prérequis

  • OBS Studio 32 ou plus récent (Aide → À propos). Les versions plus anciennes ne chargent pas le plugin.
  • iOS ou iPadOS 15 ou ultérieur.
  • Pour l’USB : iTunes sous Windows (il fournit le pilote de périphérique d’Apple), ou le démon usbmuxd sous Linux. macOS l’intègre d’office, et le Wi-Fi n’a besoin de rien de tout cela.

Page de téléchargement

Le plugin

Redémarrez OBS après chacune de ces méthodes. Sources → + doit alors proposer LensLink Camera et LensLink Screen.

Windows

Lancez LensLink-installer-windows-x64.exe. Il trouve votre dossier OBS et supprime toute copie du plugin antérieure à la version 1.0.

Méthode manuelle : décompressez lenslink-windows-x64.zip dans C:\Program Files\obs-studio\, en fusionnant les dossiers obs-plugins et data.

macOS

Ouvrez LensLink-installer-macos-universal.pkg. Le paquet n’est pas notarié : la première fois, il faut passer par clic droit → Ouvrir. Le build est universel (Apple silicon et Intel).

Vous partez plutôt du zip ? Extrayez-le dans ~/Library/Application Support/obs-studio/plugins/ et retirez l’attribut de quarantaine, sinon OBS refusera de le charger :

xattr -dr com.apple.quarantine \
  ~/Library/Application\ Support/obs-studio/plugins/lenslink.plugin

Linux

tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

Si le plugin n’apparaît pas et que le journal indique libavcodec.so.60: cannot open shared object file, vous utilisez une version antérieure à 1.8, dont l’archive était liée au FFmpeg de la machine de compilation. Mettez à jour, ou compilez depuis les sources.

Depuis les sources

Instructions complètes : obs-plugin/BUILDING.md. Sur un système de la famille Debian :

sudo apt install cmake build-essential pkg-config \
     libobs-dev libavcodec-dev libavutil-dev qt6-base-dev

cd obs-plugin
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

qt6-base-dev est facultatif : il ajoute l’indicateur de la barre d’état et le dock. Tout le reste se compile sans Qt.

L’app

App Store (recommandé)

Installez LensLink Camera depuis l’App Store. Elle est gratuite, les mises à jour arrivent toutes seules et les phrases Siri fonctionnent.

Bêta TestFlight

Pour obtenir les nouvelles versions avant leur arrivée sur l’App Store, rejoignez la bêta sur testflight.apple.com/join/N7Rth6m3. Chaque version arrive d’abord dans TestFlight ; l’App Store la reçoit une fois la mise à jour approuvée par Apple.

Installation manuelle (sideload)

Installez LensLink-unsigned.ipa depuis la dernière version avec Sideloadly ou un outil similaire.

Cette méthode s’accompagne de deux limites imposées par Apple. Avec un compte Apple gratuit, les apps installées manuellement expirent au bout de 7 jours : réinstallez l’app pour la renouveler, les réglages sont conservés.

La re-signature modifie aussi l’identifiant du bundle, ce qui rend orphelines les données compilées des phrases Siri : « Dis Siri, lance le streaming avec LensLink » reçoit un refus générique, alors que la même action fonctionne depuis Raccourcis. Utilisez lenslink://start dans un raccourci, ou installez l’app depuis l’App Store.

Xcode

Aucun .xcodeproj n’est versionné ; XcodeGen le génère.

brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

Signature et notes pour les anciennes versions de Xcode : ios-app/BUILDING.md.

Ce qui change selon le système d’exploitation

L’app, le protocole et toutes les fonctions de caméra sont identiques, quel que soit le système sur lequel tourne OBS. Ce qui change, c’est la façon dont le plugin atteint le téléphone en USB et dont il transfère les images décodées vers le GPU.

Mise à jour

Lancez le nouveau programme d’installation du plugin par-dessus l’ancien et redémarrez OBS ; l’app se met à jour via l’App Store ou TestFlight, ou en réinstallant le nouveau .ipa. Les deux moitiés négocient une version de protocole : une app un peu plus ancienne et un plugin plus récent continuent donc de fonctionner ensemble. Si une version exige un jour les deux côtés à jour, ses notes le précisent.

Désinstallation

  • Windows : l’entrée de désinstallation du programme d’installation, ou supprimez obs-plugins\64bit\lenslink.dll et data\obs-plugins\lenslink\.
  • macOS : supprimez ~/Library/Application Support/obs-studio/plugins/lenslink.plugin.
  • Linux : supprimez les fichiers extraits de ~/.config/obs-studio/plugins/.
  • App : supprimez-la comme d’habitude. Rien ne reste sur l’ordinateur.
