Configurer LensLink

Votre ordinateur
Comment le téléphone se connecte

Utilisez le câble : les étapes ci-dessous sont celles de l’USB. Passez au Wi-Fi si le téléphone doit se trouver hors de portée d’un câble.

Ce que vous voulez dans OBS
Comment vous installerez l’app

Toutes les étapes sont affichées ci-dessous, chacune marquée avec la configuration à laquelle elle s’applique. Activez JavaScript pour les filtrer.

  1. Vérifiez qu’OBS est en version 32 ou plus

    Aide → À propos.

  2. Installez le plugin Windows

    Lancez LensLink-installer-windows-x64.exe depuis la page de téléchargement.

  3. Installez le plugin macOS

    Ouvrez LensLink-installer-macos-universal.pkg depuis la page de téléchargement avec clic droit → Ouvrir. Le paquet n’est pas notarié, donc un double-clic est refusé.

  4. Installez le plugin Linux

    tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

  5. Redémarrez OBS

    Sources → + propose désormais LensLink Camera et LensLink Screen.

  6. Installez l’app App Store

    Installez LensLink Camera depuis l’App Store. Pour avoir les nouvelles versions avant leur arrivée sur l’App Store, rejoignez plutôt la bêta TestFlight.

  7. Installez l’app Installation manuelle

    LensLink-unsigned.ipa depuis la dernière version, via Sideloadly.

    Avec un compte Apple gratuit, l’app expire au bout de 7 jours, et la re-signature casse les phrases Siri : utilisez lenslink://start dans un raccourci.

  8. Compilez l’app Xcode

    brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

  9. Installez iTunes Windows USB

    Il fournit le pilote de périphérique d’Apple. Sans lui, l’USB ne voit pas le téléphone.

  10. Vérifiez qu’usbmuxd est installé Linux USB

    Le plugin se connecte à /var/run/usbmuxd. La plupart des environnements de bureau le fournissent ; sinon, installez le paquet usbmuxd.

  11. Branchez le téléphone et touchez Se fier USB

    Déverrouillez d’abord le téléphone, et utilisez un câble de données.

  12. Mettez les deux appareils sur le même réseau Wi-Fi

    Les réseaux invités et l’isolation des clients bloquent la connexion.

  13. Ouvrez LensLink sur le téléphone

    Choisissez l’objectif, la résolution, la fréquence d’images et le codec.

    L’écran de configuration affiche son adresse : touchez-la pour la copier.

  14. Autorisez l’accès au Réseau local Wi-Fi

    Nécessaire pour que le téléphone apparaisse par son nom. Saisir son adresse IP fonctionne sans.

  15. Ajoutez la source Caméra

    Sources → + → LensLink Camera. Une par téléphone.

  16. Ajoutez la source Écran

    Sources → + → LensLink Screen.

  17. Reliez-la au téléphone USB

    Réglez Connexion sur Câble USB.

  18. Reliez-la au téléphone Wi-Fi

    Choisissez-le dans la liste Téléphone, ou saisissez son IP.

  19. Démarrez la caméra Caméra

    Touchez Démarrer la caméra, ou laissez simplement l’app ouverte : OBS la démarre pour vous.

  20. Lancez la diffusion Écran

    Recopier l’écran → LensLink Screen → Commencer la diffusion. Vous pouvez ensuite quitter l’app.

  21. Figez la taille de la source Écran

    Clic droit → Transformer → Éditer la transformation…, puis réglez Type de Cadre sur Mettre à l’échelle à partir des dimensions intérieures : changer d’app ne pourra plus redimensionner votre mise en page.

  22. Calez votre micro Caméra

    Facultatif : choisissez-le sous Source audio de synchro labiale, activez le retard et la Calibration auto, activez Référence de synchro labiale auto dans l’app, puis parlez pendant 15 secondes. Détails.

Vos réponses figurent dans la barre d’adresse : copiez-la pour envoyer exactement cette configuration à quelqu’un. Vous bloquez ? La ligne État de la source indique l’étape qui échoue : ce que signifie chacune. Plus de détails dans Installer et Connecter.
