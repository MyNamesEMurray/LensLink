Télécharger LensLink

Deux moitiés qui communiquent entre elles : un plugin pour OBS Studio, et une app sur votre iPhone ou iPad. Il vous faut les deux.

Dernière version — Publiée le — Notes de version

Impossible d’obtenir la liste des fichiers depuis GitHub. Les boutons ci-dessous mènent quand même à la dernière version.

Partie 1

Le plugin OBS

Ajoute les sources LensLink Camera et LensLink Screen à OBS Studio 32+. Redémarrez OBS ensuite.

  • Programme d’installation Windows LensLink-installer-windows-x64.exe Télécharger
  • Windows, installation manuelle lenslink-windows-x64.zip Télécharger
  • Paquet macOS LensLink-installer-macos-universal.pkg Télécharger
  • macOS, installation manuelle lenslink-macos-universal.zip Télécharger
  • Linux lenslink-linux-x86_64.tar.gz Télécharger

Étapes par plateforme : guide d’installation. Ou compilez-le depuis les sources.

Partie 2

L’app iPhone / iPad

Elle capture la vidéo et attend la connexion d’OBS. iOS ou iPadOS 15+. Gratuite sur l’App Store, elle se met à jour toute seule.

Télécharger dans l’App Store

LensLink Camera, gratuite, sans achats intégrés.

  • Bêta TestFlight Les nouvelles versions avant la validation d’Apple Rejoindre
  • Installation manuelle (sideload), version non signée LensLink-unsigned.ipa Télécharger

Avec un compte Apple gratuit, les apps installées manuellement expirent au bout de 7 jours et les phrases Siri ne fonctionnent plus (pourquoi).

Avant d’installer

Les deux points sur lesquels on bute le plus souvent.

OBS Studio 32 ou plus récent Aide → À propos. Les versions plus anciennes ne chargent pas le plugin.
Un service USB, pour l’USB uniquement Le pilote de périphérique d’Apple est fourni avec iTunes. Linux a besoin à la place du démon usbmuxd ; macOS l’intègre d’office. Le Wi-Fi n’a besoin d’aucun des deux.
