LensLinkのセットアップ

お使いのコンピュータ
スマートフォンの接続方法

ケーブルを使ってください。以下はUSB用の手順です。ケーブルが届かない場所にスマートフォンを置く必要がある場合は、Wi-Fiに切り替えてください。

OBSで使いたいもの
アプリのインストール方法

すべての手順を下に表示し、それぞれに対象のセットアップを示すタグを付けています。JavaScriptを有効にすると、手順を絞り込めます。

  1. OBSが32以降か確認

    ヘルプ → OBS Studioについて。

  2. プラグインをインストール Windows

    ダウンロードページからLensLink-installer-windows-x64.exeを実行します。

  3. プラグインをインストール macOS

    ダウンロードページから入手したLensLink-installer-macos-universal.pkgを、右クリック → 開くで開きます。公証されていないため、ダブルクリックでは開けません。

  4. プラグインをインストール Linux

    tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

  5. OBSを再起動

    ソース → +にLensLink CameraとLensLink Screenが表示されるようになります。

  6. アプリをインストール App Store

    App StoreからLensLink Cameraをインストールします。App Storeより先に新しいバージョンを使いたい場合は、代わりにTestFlightベータに参加してください。

  7. アプリをインストール サイドロード

    最新リリースのLensLink-unsigned.ipaを、Sideloadlyでインストールします。

    無料のApple IDでは7日で期限切れになり、再署名するとSiriのフレーズが使えなくなります。ショートカットでlenslink://startを使ってください。

  8. アプリをビルド Xcode

    brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

  9. iTunesをインストール Windows USB

    Appleのデバイスドライバが含まれています。これがないと、USBでスマートフォンを認識できません。

  10. usbmuxdがインストールされているか確認 Linux USB

    プラグインは/var/run/usbmuxdに接続します。ほとんどのデスクトップ環境には含まれていますが、ない場合はusbmuxdパッケージをインストールしてください。

  11. 接続して「信頼」をタップ USB

    先にスマートフォンのロックを解除し、データ通信に対応したケーブルを使ってください。

  12. 両方を同じネットワークに接続 Wi-Fi

    ゲストネットワークやクライアント分離が有効なネットワークでは接続できません。

  13. スマートフォンでLensLinkを開く

    レンズ、解像度、フレームレート、コーデックを選びます。

    セットアップ画面にアドレスが表示されます。タップするとコピーできます。

  14. ローカルネットワークへのアクセスを許可 Wi-Fi

    スマートフォンを名前で表示するのに必要です。IPを直接入力する場合は不要です。

  15. ソースを追加 カメラ

    ソース → + → LensLink Camera。スマートフォン1台につき1つです。

  16. ソースを追加 画面

    ソース → + → LensLink Screen。

  17. スマートフォンを指定 USB

    接続をUSBケーブルに設定します。

  18. スマートフォンを指定 Wi-Fi

    スマートフォンのドロップダウンから選ぶか、IPを入力します。

  19. カメラを開始 カメラ

    カメラを開始をタップします。または、アプリを開いたままにしておけばOBSが開始します。

  20. ブロードキャストを開始 画面

    画面をミラーリング → LensLink Screen → ブロードキャストを開始。開始後はアプリを離れてもかまいません。

  21. ソースのサイズを固定 画面

    右クリック → 変換 → 変換の編集…で境界の種類を内側に合わせるに設定します。これで、アプリを切り替えてもレイアウトのサイズが変わりません。

  22. マイクのタイミングを合わせる カメラ

    任意の手順です。リップシンク用音声ソースでマイクを選び、遅延と自動キャリブレーションを有効にし、アプリで自動リップシンク用リファレンスをオンにして、15秒ほど話します。詳細。

回答内容はアドレスバーに入っています。コピーして送れば、このセットアップをそのまま共有できます。うまくいかない場合は、ソースのステータスの行に失敗している段階が表示されます。それぞれの意味を確認してください。さらに詳しくはインストールと接続をご覧ください。
