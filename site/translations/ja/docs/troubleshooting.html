トラブルシューティング

当てはまる症状を探してください。ほとんどの報告は、2つの添付があれば解決できます。OBSのログ（ヘルプ → ログファイル → 現在のログを表示）と、アプリのオプション → カメラ診断です。

OBSにソースが表示されない

  • OBSを再起動してください。プラグインが読み込まれるのは起動時の1回だけです。
  • OBSが32以降であることを確認してください（ヘルプ → OBS Studioについて）。
  • Linuxで、ログにlibavcodec.so.60: cannot open shared object fileと出る場合：v1.7.xまでのtarballはビルドマシンのFFmpegにリンクしていたため、メジャーバージョンがそれと一致するディストリビューションでしか読み込めませんでした。アップデートするか、ソースからビルドしてください。ソースからビルドすれば、お使いの環境のFFmpegにリンクされます。
  • macOSでzipからインストールした場合：検疫（quarantine）フラグを解除してください。解除しないと、OBSは何も表示せずに読み込みを拒否します。

ソース名が「iOS Camera」になっている、または更新が反映されないように見える

1.0より前のバージョン（ios-camera-source.dll）がまだインストールされていて、現在のバージョンより優先されています。ログには"Source 'ios_camera_source' already exists"と出力されます。次の両方を削除して再起動してください。 

obs-plugins\64bit\ios-camera-source.dll
data\obs-plugins\ios-camera-source\

現在のインストーラーは、これを自動的に削除します。

USBデバイスが見つからない（Windows）

  • iTunesをインストールしてください。AppleのデバイスドライバーはiTunesに含まれています。Windowsではこれを避ける方法はありません。
  • スマートフォンのロックを解除した状態で、「信頼」をタップしてください。
  • データ通信対応のケーブルを使ってください。充電専用ケーブルかデータ通信用ケーブルかは、画面上の表示からは判別できません。

「デバイスは見つかりましたが、LensLinkアプリに接続できません」と表示される場合、ケーブルとドライバーには問題ありません。アプリがフォアグラウンドにないか、スマートフォンがロックされています。

「スマートフォン」のドロップダウンにスマートフォンが表示されない

名前の通知には、iOSのローカルネットワークの許可が必要です。求められたときに許可するか、設定 → プライバシーとセキュリティ → ローカルネットワーク → LensLinkで許可してください。IPを入力すれば、許可に関係なく接続できます。

また、両方のデバイスが同じネットワークにあること、そのネットワークがゲストネットワークやクライアント分離が有効なネットワークでないことも確認してください。

1週間後にアプリが動かなくなる（サイドロードのみ）

無料のApple IDでサイドロードしたアプリは、7日ごとに期限が切れます。再インストールして更新するか（設定は保持されます）、期限切れのないApp Store版に切り替えてください。

「Hey Siri、LensLinkでストリーミングを開始」が認識されない（サイドロードのみ）

再署名するとバンドルIDが書き換わり、コンパイル済みのフレーズデータとの関連が失われます。そのため、ショートカットからは同じアクションが動作するのに、Siriは応じません。App Store版を使うか、lenslink://startを使うショートカットを利用してください。また、アプリを一度以上起動していること、設定 → Siriと検索 → LensLinkで「Use with Siri」がオンになっていることも確認してください。

コントロールセンターのビデオエフェクトが表示されない、またはグレーアウトしている

これらはiOSのエフェクトで、アプリがカメラを使用している間にコントロールセンターで切り替えます。iOSがこれらを提供するのは特定のカメラとフォーマットに限られ（一般的には前面カメラで、1920×1440以下）、多くのiPhoneでは背面カメラでは使えません。

  • オプション → カメラ診断で、お使いのデバイスで使えるものをカメラとフォーマットごとに確認できます。
  • LensLinkは、設定上可能であれば、すでにエフェクトに対応したフォーマットを選んでいます。
  • トグルがグレーアウトしている場合は、フレームレートが高すぎます。フレームレートを下げ、オプション → システムのビデオエフェクトを許可をオンにしてください。
  • 1.8.1より前はパネル自体が表示されませんでした。iOSは、各エフェクトをInfo.plistで宣言したアプリにしかこのパネルを表示しないためです。現在のLensLinkは宣言しています。

Appleのカメラアプリのフィルタやフォトグラフスタイルは、サードパーティ製のアプリでは使えません。代わりにOBSのフィルタを使ってください（右クリック → フィルタ）。

画面ブロードキャストが接続しない

  • サイドロードしたビルド：再署名によって、拡張機能が気づかないうちに壊れることがあります。拡張機能がない場合は、アプリのホーム画面にある「画面ミラーリング」セクションに警告が表示されます。TestFlight版とApp Store版には影響ありません。
  • ソースがLensLink Screenソースであることを確認してください。Cameraソースにブロードキャストが送られた場合は、そのステータス欄にその旨が表示されます。

音声が出ない、または聞こえない

  • ブロードキャスト中はDRMアプリの音声が出ません：iOSがApple Music、Spotify、Netflixをミュートします。ゲーム、アプリ、ブラウザの音声は問題ありません。
  • 録音はされるが聞こえない：OBSのオーディオの詳細プロパティで、音声モニタリングをモニターと出力に設定してください。
  • OBSにスマートフォンのマイク音声が届かない：スマートフォンのマイクをOBSに送信をオンにしてください。自動リップシンク用リファレンスがオンの場合は送信されません。マイク1つにつき、役割は1つです。

2つのソースに1台のスマートフォン

スマートフォンが映像を送れるのは一度に1つのソースだけで、2つ目のソースにはデバイスが使用中と表示されます。例外はこのソースがどこにも表示されていないときは切断を使う場合です。非表示のソースはスマートフォンを解放するので、別々のシーンにあるソースで共有できます。

ズームするとWi-Fiで遅延が急上昇する

デジタルズームはセンサーのノイズを拡大し、ノイズは圧縮効率が悪いため、ビットレートが急上昇します。望遠レンズを使うか、USBに切り替えてください。

「接続済みですが、このOBSビルドではストリームをデコードできません」

そのビルドにはHEVCデコーダーがありません。アプリをH.264に切り替えてください。映像は同じで、帯域が増えるだけです。

映像が一面緑色になる

ほとんどの場合、バーチャルグリーンバックが、被写体を見失った状態で設計どおりに動作しています。スマートフォンはあなた以外のすべてをクロマキー用の緑で塗りつぶすため、セグメンテーションがあなたを見失うと（フレームから外れた、または被写体までの距離が近すぎる設定になっているなど）、フレーム全体が背景になります。設定はスマートフォン側にあるため、OBSとスマートフォンを両方再起動しても、この状態は続きます。

確認するには、アプリでグリーンバックをオフにしてください。オンのまま使いたい場合は、クロマキーフィルタがまだソースに付いているか確認してください。プラグインがフィルタを追加するのは最初の1回だけで、削除されたフィルタを追加し直すことはありません。どちらの状況かは、ソースのステータスの行に表示されます。

また、グリーンバックはフレームごとにスマートフォンに相当な処理をさせるため、配信中に動作が遅れるデバイスでは、グリーンバックをオフにして試してみる価値があります。

OBSのソースに一時停止マーク付きのぼやけた映像が表示される

ストリームは壊れているのではなく、一時停止中です。スマートフォンは接続されたままでカメラも動作していますが、映像は送出されていません。誰かが一時停止した（スマートフォンのライブ画面、Webパネル、ソースのプロパティのどれにもボタンがあります）か、iOSがカメラを中断したかのどちらかです。後者は、iPadで別のアプリがLensLinkと並んでカメラを開いたときに起こります。上記のどこからでも再開できます。中断による場合は、カメラが戻ると自動的に再開します。

スマートフォンでアプリを切り替えると映像が止まる、または黒くなる

想定どおりの動作です。iOSは画面に表示されていないアプリのカメラキャプチャを停止させるため、LensLinkはストリームを正常に停止し、ソースは空白になります。スマートフォンをロックしても同じです。例外は画面ブロードキャストで、アプリを切り替えても動作し続けます。また、対応するiPadでは、Split View、Slide Over、ステージマネージャで別のアプリと並べても配信を続けられます。

このウインドウには独自のボタンがありません（iOS 15より後、iOSはこの種のウインドウにボタンを描画しなくなりました）。LensLinkに戻るにはウインドウをタップしてください。ウインドウを画面の端の外に押し出すと隠れた状態になりますが、iOSは見えているウインドウにしかカメラを使わせません。そのため、キャプチャが一時停止し、緑のカメラインジケータが消え、ウインドウを戻すまでOBSは最後のフレームを表示し続けます。ウインドウを戻すと、ストリームは自動的に再開します。これはバックグラウンドでのキャプチャに関するiOSのルールで、LensLinkの設定ではありません。スマートフォンに戻らずに停止または一時停止するには、OBSかWebパネルで停止または一時停止を押すか、Siriに配信の停止を頼んでください。

iPadでは、Split View、Slide Over、ステージマネージャでLensLinkを別のアプリと並べて画面に表示したままにすれば、マルチタスク中のカメラアクセスに対応したモデル（iPadOS 16以降）ではカメラが動作し続けます。カメラを共有できないiPadでは、ステータスにカメラ一時停止中：このiPadは画面上でカメラを共有できませんと表示されます。その場合は、LensLinkをフルスクリーンで使ってください。

どれにも当てはまらない場合

ツール → LensLink設定 → 診断レポートをコピーを実行し、GitHubのIssueに貼り付けてください。バージョン、ハードウェア、グラフィックデバイス、設定、ソースごとの接続状態が含まれます。最後のソケットエラーも含まれるので、「アプリが動いていなかった」のか「OSが接続を拒否した」のかを区別できます。映像、音声、個人データは含まれません。

Qt UIがない環境やスクリプトからは、curl localhost:9980/api/diagnosticsを使います。レポートはOBSのログにも出力されるので、ヘルプ → ログファイル → 現在のログファイルをアップロードでも送れます。

あわせて、アプリのオプション → カメラ診断と、OBSログへの詳細な診断出力をオンにして問題を1回再現したときのOBSのログも添付すると役立ちます。
