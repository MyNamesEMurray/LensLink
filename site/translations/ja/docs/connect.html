OBSとスマートフォンを接続

映像、カメラ操作、クロック同期、ステータスを、ローカルネットワークまたはUSBケーブル上の1本のTCP接続で運びます。インターネットには一切触れません。

かんたんな手順

  1. スマートフォンで

    LensLinkを開き、カメラとフォーマットを選んでカメラを開始をタップします。セットアップ画面にスマートフォンのWi-Fiアドレスが表示され、タップするとコピーできます。

    OBSからリモート開始がオン（デフォルト）なら、アプリを開いてアイドル状態にしておくだけで、OBSがカメラを開始します。

  2. OBSで

    ソース → + → LensLink Camera。スマートフォン1台につき1つのソースです。

  3. スマートフォンを指定

    Wi-Fi：スマートフォンのドロップダウンからデバイスを選ぶか、アプリに表示されているIPを入力します。

    USB：ケーブルを接続し、接続をUSBケーブルに設定します。

1〜2秒で映像が表示されます。ストリーミング中にアプリを離れるとソースは真っ暗になります。iOSは画面に表示されていないアプリのカメラキャプチャを停止するためです。対応するiPadでは、Split View、Slide Over、ステージマネージャで別のアプリと並べている間もLensLinkはストリーミングを続けます。

Wi-Fi

両方のデバイスが同じネットワークに接続され、そのネットワークでデバイス間の通信が許可されている必要があります。ゲストネットワーク、クライアント分離が有効なアクセスポイント、多くのオフィスや大学のネットワークでは通信がブロックされます。スマートフォンのインターネット共有にコンピュータを接続する場合はブロックされません。

スマートフォンを名前で探す

アプリは開いている間Bonjourで自身を告知し、スマートフォンのドロップダウンに見つかったデバイスが一覧表示されます。一覧にスマートフォンが表示されないのにIPの入力では接続できる場合は、この告知にiOSが要求するローカルネットワークのアクセス許可がアプリにありません。確認画面が表示されたときに許可するか、設定 → プライバシーとセキュリティ → ローカルネットワーク → LensLinkで許可してください。

スマートフォンには新しいDHCPリースが割り当てられることもあり、これも名前で選ぶべきもう1つの理由です。アドレスを入力したい場合は、ルーターでアドレスを予約してください。

USB

大事な場面ではUSBを使ってください。ネットワークを介さず、遅延が最も安定し、エンコード中にスマートフォンが充電されます。映像のエンコードはスマートフォンにとって最も負荷の高い処理の1つなので、充電できるのは大きな利点です。

  1. Windowsのみ：iTunesをインストール

    Appleのデバイスドライバが含まれています。これがないと、どのケーブルでも接続できません。

  2. 接続して「信頼」をタップ

    確認画面を表示するにはスマートフォンのロックを解除しておく必要があり、ケーブルはデータ通信に対応したものが必要です。

  3. 「接続」を「USBケーブル」に設定

    複数台のスマートフォンを使うのでなければ、USBデバイスは自動のままにしておきます。

複数台のスマートフォンを接続している場合は、各ソースのUSBデバイスを「自動」ではなく特定のデバイスに設定してください。そうすれば、接続した順序にかかわらず、同じスマートフォンが常に同じソースに映像を送ります。指定したデバイスが接続されていない場合、ソースは待機し、その旨を表示します。

複数台のスマートフォンを同時に使う

スマートフォン1台につきLensLink Cameraソースを1つ使います。それぞれが独自の接続、操作、状態表示を持ち、ブラウザパネルにはソースごとのタブが追加されます。

1台のスマートフォンが同時に映像を送れるソースは1つだけです。同じデバイスを指定した2つ目のソースは、使用中である旨を表示します。例外として、このソースがどこにも表示されていないときは切断をオンにすると、非表示のソースはスマートフォンを解放します。そのため、あるシーンのCameraソースと別のシーンのScreenソースで1台を共有できます。

ステータス欄の読み方

すべてのLensLinkソースのプロパティの先頭にはステータスの行があり、失敗している段階を正確に示します。

ステータス意味
接続済み：…ストリーミング中。デバイス、フォーマット、測定した遅延を表示します。
接続済み：カメラはアイドル状態ですスタンバイ。アプリには接続できますが、キャプチャしていません。ここ、ブラウザパネル、スマートフォンのいずれかから開始してください。
スマートフォンのカメラを起動中…リモート開始を送信済みで、カメラが起動しているところです。
スマートフォンに接続を試行中：…アドレスが間違っているか到達できない、またはアプリがフォアグラウンドにありません。
スマートフォンのIPアドレスを入力してくださいWi-Fiソースにホストが設定されていません。
USBでデバイスが検出されませんケーブルを確認し、「信頼」をタップしてください。Windowsでは、iTunesがインストールされているか確認してください。
デバイスは見つかりましたが、LensLinkアプリに接続できませんケーブルは問題ありません。スマートフォンのロックを解除し、アプリをフォアグラウンドにしてください。
選択したUSBデバイスの接続を待機中接続されていないデバイスが指定されています。
このデバイスは別のLensLinkソースで使用中です2つのソースが1台のスマートフォンを指定しています。上記を参照してください。
切断：再接続中接続が切れ、ソースが再接続しています。
一時停止中：ソースが非表示ですこのソースがどこにも表示されていないときは切断がオンで、ソースがどこにも表示されていません。
スマートフォンが画面ブロードキャストを送信中ですソースの種類が違います。ブロードキャストにはLensLink Screenソースを使ってください。
接続済みですが、このOBSビルドではストリームをデコードできませんそのビルドにHEVCデコーダがありません。アプリをH.264に切り替えてください。

安定して使うために

  • 数値を確認しましょう。OBSのステータスバーにはスマートフォンごとに1行（LensLink: iPhone 60 fps · 11.9 Mb/s · 43 ms）が表示され、表示 → ドック → LensLinkで同じ内容をパネルとして表示できます。
  • 混雑には自動で対処します。アプリは遅延をためこまず、一時的に画質を下げてから回復します。
  • バッテリーを節約するには、このソースがどこにも表示されていないときは切断を使います。ソースが非表示の間、スマートフォンはエンコードを停止します。
  • ストリームは暗号化されていません。信頼できる自宅やスタジオのネットワークでの使用を想定しています。

接続できない場合

  1. アプリは、ロックを解除したスマートフォンの画面に表示されていますか？
  2. Wi-Fi：同じネットワークに接続していますか？一方のデバイスだけがゲストSSIDに接続していませんか？
  3. USB：データ通信対応のケーブルを使い、信頼をタップしましたか？
  4. それ以外は、上の表でステータス欄に一致する行に従ってください。

それでも解決しない場合：トラブルシューティング。
