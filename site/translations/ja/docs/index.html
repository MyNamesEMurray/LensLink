ドキュメント

互いに通信する2つのプログラム、つまりOBSのプラグインとスマートフォンのアプリで構成されています。このドキュメントでは、両方のインストール、接続方法、そしてそれぞれのすべての設定を説明します。

お急ぎの場合：セットアップガイドが4つの質問をして、回答に合った手順だけを表示します。またはインストール、接続の順に読んでください。内容は同じで、すべてを詳しく説明しています。

全体の仕組み

アプリは映像をキャプチャしてハードウェアでH.264またはHEVCにエンコードし、TCPポート9979で待ち受けます。プラグインはネットワーク経由、またはAppleのUSBデバイスサービス経由でそのポートに接続し、可能な場合はGPUでデコードして、通常のソースとしてOBSにフレームを渡します。

クラウドサービスもアカウントも不要です。両者が互いに見えていれば、LensLinkは動作します。

構成要素動作する場所役割
LensLinkアプリiPhone / iPadキャプチャ、エンコード、待ち受け。画面に表示されている間（対応iPadでは別のアプリと並べて表示している間も）ストリーミングします。
LensLink CameraOBSソースカメラのストリーム、その操作、リップシンク。

はじめに

  • インストールWindows、macOS、Linuxへのプラグインのインストール。App Store、TestFlight、サイドロード、Xcodeによるアプリのインストール。
  • OBSとスマートフォンを接続Wi-Fi、USB、複数台のスマートフォン、すべてのステータスメッセージの意味。
  • カメラ、レンズ、画質フォーマット、マニュアル露出、HDR、Apple Log、グリーンバック、設定の記憶。
  • 画面ミラーリング画面と音声のブロードキャスト、ソースのサイズの固定。
  • 音声とリップシンクスマートフォンをマイクとして使う方法と、お使いのマイクの自動タイミング調整。
  • リモート開始OBS、Siri、ショートカット、URLからカメラを開始する。
  • ブラウザコントロールパネルポート9980のパネルと、その裏にあるHTTP API。
  • 設定リファレンスすべてのソースのプロパティ、プラグインの設定、アプリのオプション。
  • 遅延とパフォーマンス遅延の内訳と、GPUデコードパイプライン。
  • トラブルシューティング症状ごとに、探すべきログ行とあわせて解説します。

用語

以下の用語は、アプリ、プラグイン、このドキュメント全体を通じて、それぞれ特定の1つのものを指します。

セットアップ画面アプリの最初の画面。ストリーミングを始める前の、コンピュータのカード、カメラの各行、2つの開始ボタンがある画面です。
ライブ画面ストリーミング中の全画面表示。映像、レンズボタン、ワンタップで開ける調整トレイがあります。
スタンバイアプリが開いたままアイドル状態で、OBSが接続済みでカメラを開始できる状態。アンバーで表示されます。
タリーランプソースがOBSでどうなっているかを示す色付きの枠。オンエア、プレビュー中、その他選択したステータスを表示します。
アイドル表示最後に触れてから10秒後にライブ画面が切り替わる表示。
リップシンク用リファレンスタイミング信号としてのみ送られるスマートフォンのマイク音声。配信で聞こえることはありません。

ヘルプ

トラブルシューティングでは、既知の失敗パターンを、それぞれが出力するログ行とあわせて解説しています。新しい問題はGitHubでissueを作成し、OBSのログ（ヘルプ → ログファイル）とオプション → カメラ診断を添付してください。
