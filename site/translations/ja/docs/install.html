インストール

OBSのプラグインとスマートフォンのアプリ、両方が必要です。お使いの環境に合った手順だけを見たい場合は、セットアップガイドを使ってください。

動作要件

  • OBS Studio 32以降（ヘルプ → OBS Studioについて）。古いバージョンではプラグインが読み込まれません。
  • iOSまたはiPadOS 15以降。
  • USB接続の場合：WindowsではiTunes（Appleのデバイスドライバが含まれています）、Linuxではusbmuxdデーモンが必要です。macOSには標準で組み込まれており、Wi-Fiではどれも不要です。

ダウンロードページ

プラグイン

どの方法でも、インストール後にOBSを再起動してください。ソース → +にLensLink CameraとLensLink Screenが表示されるはずです。

Windows

LensLink-installer-windows-x64.exeを実行します。OBSのフォルダを自動で見つけ、1.0より前のバージョンのプラグインがあれば削除します。

手動でインストールする場合は、lenslink-windows-x64.zipをC:\Program Files\obs-studio\に展開し、obs-pluginsフォルダとdataフォルダを統合します。

macOS

LensLink-installer-macos-universal.pkgを開きます。パッケージは公証されていないため、初回は右クリック → 開くで開く必要があります。ユニバーサルビルドなので、Appleシリコン搭載機とIntel搭載機の両方で動作します。

zipからインストールする場合は、~/Library/Application Support/obs-studio/plugins/に展開し、隔離フラグを解除してください。解除しないとOBSが読み込みを拒否します。

xattr -dr com.apple.quarantine \
  ~/Library/Application\ Support/obs-studio/plugins/lenslink.plugin

Linux

tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

プラグインが表示されず、ログにlibavcodec.so.60: cannot open shared object fileと出る場合は、1.8より前のリリースを使っています。そのtarballはビルドマシンのFFmpegにリンクされていました。アップデートするか、ソースからビルドしてください。

ソースから

詳しい手順：obs-plugin/BUILDING.md。Debian系のシステムでは次のとおりです。

sudo apt install cmake build-essential pkg-config \
     libobs-dev libavcodec-dev libavutil-dev qt6-base-dev

cd obs-plugin
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

qt6-base-devは任意です。ステータスバーの表示とドッキング可能なパネルが追加されます。それ以外はQtなしでビルドできます。

アプリ

App Store（おすすめ）

App StoreからLensLink Cameraをインストールします。無料で、アップデートは自動で届き、Siriのフレーズも使えます。

TestFlightベータ

App Storeより先に新しいバージョンを使うには、testflight.apple.com/join/N7Rth6m3から参加してください。すべてのリリースはまずTestFlightに配信され、Appleがアップデートを承認するとApp Storeにも配信されます。

サイドロード

最新リリースのLensLink-unsigned.ipaを、Sideloadlyなどのツールでインストールします。

この方法には、Appleによる制限が2つあります。無料のApple IDでは、サイドロードしたアプリは7日で期限切れになります。再インストールすれば更新でき、設定は保持されます。

また、再署名するとバンドルIDが書き換わるため、コンパイル済みのSiriフレーズのデータが使えなくなります。ショートカットからは同じアクションが動作するのに、「Hey Siri、LensLinkでストリーミングを開始」には汎用的な拒否の応答が返ります。ショートカットでlenslink://startを使うか、App Storeからインストールしてください。

Xcode

.xcodeprojはリポジトリに含まれていません。XcodeGenで生成します。

brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

署名と古いXcodeに関する注意：ios-app/BUILDING.md。

OSによる違い

アプリ、プロトコル、すべてのカメラ機能は、OBSがどこで動いていても同じです。違うのは、プラグインがUSB経由でスマートフォンにアクセスする方法と、デコードしたフレームをGPUに渡す方法です。

アップデート

新しいプラグインのインストーラを古いものの上から実行し、OBSを再起動します。アプリはApp StoreかTestFlightでアップデートするか、新しい.ipaを再インストールします。両者はプロトコルのバージョンをネゴシエートするため、少し古いアプリと新しいプラグインの組み合わせでも動作します。両方の更新が必要なリリースでは、リリースノートにその旨を記載します。

アンインストール

  • Windows：インストーラのアンインストール項目を使うか、obs-plugins\64bit\lenslink.dllとdata\obs-plugins\lenslink\を削除します。
  • macOS：~/Library/Application Support/obs-studio/plugins/lenslink.pluginを削除します。
  • Linux：~/.config/obs-studio/plugins/から展開したファイルを削除します。
  • アプリ：通常どおり削除します。コンピュータには何も残りません。
