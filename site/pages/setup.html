Set up LensLink

Your computer
How the phone connects

Use the cable — the steps below are the USB ones. Switch to Wi-Fi if the phone has to sit somewhere a cable can't reach.

What you want in OBS
How you'll install the app

Every step is shown below, tagged with the setup it belongs to. Turn on JavaScript to filter them.

  1. Check OBS is 32 or newer

    Help → About.

  2. Install the plugin Windows

    Run LensLink-installer-windows-x64.exe from the download page.

  3. Install the plugin macOS

    Open LensLink-installer-macos-universal.pkg from the download page with right-click → Open. It isn't notarized, so a double-click is refused.

  4. Install the plugin Linux

    tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

  5. Restart OBS

    Sources → + now lists LensLink Camera and LensLink Screen.

  6. Install the app TestFlight

    Join the beta, then install from TestFlight.

  7. Install the app Sideload

    LensLink-unsigned.ipa from the latest release, via Sideloadly.

    A free Apple ID expires it after 7 days, and re-signing breaks the Siri phrases — use lenslink://start in a Shortcut.

  8. Build the app Xcode

    brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

  9. Install iTunes Windows USB

    It supplies Apple's device driver. USB can't see the phone without it.

  10. Check usbmuxd is installed Linux USB

    The plugin connects to /var/run/usbmuxd. Most desktops ship it; install the usbmuxd package if not.

  11. Plug in and tap Trust USB

    Unlock the phone first, and use a data cable.

  12. Put both on the same network Wi-Fi

    Guest networks and client isolation block it.

  13. Open LensLink on the phone

    Pick lens, resolution, frame rate and codec.

    The Setup screen shows its address — tap to copy.

  14. Allow the Local Network permission Wi-Fi

    Needed for the phone to appear by name. Typing its IP works without it.

  15. Add the source Camera

    Sources → + → LensLink Camera. One per phone.

  16. Add the source Screen

    Sources → + → LensLink Screen.

  17. Point it at the phone USB

    Set Connection to USB cable.

  18. Point it at the phone Wi-Fi

    Pick it in the Phone dropdown, or type the IP.

  19. Start the camera Camera

    Tap Start camera stream — or leave the app open and OBS starts it for you.

  20. Start the broadcast Screen

    Start screen broadcast → LensLink Screen → Start Broadcast. You can leave the app afterwards.

  21. Pin the source size Screen

    Right-click → Transform → Edit Transform…, set Bounding Box Type to Scale to inner bounds, so switching apps can't resize your layout.

  22. Line up your microphone Camera

    Optional: pick it under Lip-sync audio source, enable the delay and Auto-calibrate, turn on Auto lip-sync reference in the app, and talk for fifteen seconds. Detail.
