Screen mirroring

A second source type, LensLink Screen, receives an iOS screen broadcast: your whole phone or tablet screen with the app's audio, from any app on the device. It is encoded in HEVC, so it stays bandwidth-friendly even at a tablet's resolution.

Setting it up

  1. Add the source in OBS

    Sources → + → LensLink Screen, then point it at the phone exactly like a camera source: pick it in the Phone dropdown, type its IP, or set Connection to USB cable.

  2. Start the broadcast on the phone

    In the app's Screen mirror section, tap Start screen broadcast, choose LensLink Screen in the picker, and tap Start Broadcast. The system picker is required — iOS will not start a broadcast any other way.

  3. Leave the app if you like

    Unlike the camera, a broadcast keeps running when you switch apps — that is the whole point. Go play the game or open the app you are demonstrating.

Camera and screen are different sources. Each type accepts only its own stream. A Screen source fed a camera stream says so in its Status field and tells you which source to switch to, rather than showing nothing.

Audio

  • App and system audio comes through as the source's audio. Game sound, browser video, app effects.
  • DRM-protected audio is muted by iOS during any screen broadcast — Apple Music, Spotify, Netflix. That is an iOS rule applied to every broadcast extension on the platform, not something LensLink can opt out of.
  • Your microphone is not sent. Mic yourself in OBS as usual. (The camera source can carry the phone's microphone; the screen source deliberately does not.)

To hear the audio on the computer rather than only record or stream it, set the source's Audio Monitoring to Monitor and Output in OBS's Advanced Audio Properties.

Locking the source size

A screen mirror reports whatever resolution iOS is broadcasting, and that changes between apps and orientations — so the OBS source can resize when you switch apps, disturbing your layout. Pin it to a fixed box instead:

  1. Right-click the source → Transform → Edit Transform…
  2. Set Bounding Box Type to Scale to inner bounds ("Fit").
  3. Give the bounding box the size you want the mirror to occupy.

What the Screen source does not have

No camera controls, and no browser panel — there is nothing to zoom or focus. Its properties are just the connection, the decoding options and the diagnostics.

Sharing one phone between two sources

A phone can feed one source at a time. If you want a Camera source in one scene and a Screen source in another, enable Disconnect when this source isn't shown anywhere on both: a hidden source releases the phone, so switching scenes hands the device from one to the other.

When the broadcast will not connect

The broadcast extension is a separate process from the app, which makes its failures hard to see. The app has a built-in check for exactly this:

  • Open Screen mirror tools → Check broadcast link while a broadcast is running. It verifies the extension is alive on the device, independent of OBS.
  • If the check fails on a sideloaded build, re-signing has most likely broken the extension — this is a known consequence of rewriting bundle IDs. The TestFlight build does not have the problem.
  • If the check passes but OBS shows nothing, the problem is the connection, not the extension: see Reading the Status field.
