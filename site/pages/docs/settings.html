Settings reference

Three places hold settings, and each holds a different kind. Per-source properties live on the source; anything with one value for the whole plugin lives under Tools; anything about the phone lives in the app.

Source properties (LensLink Camera)

Right-click the source → Properties, or double-click it.

PropertyWhat it does
StatusRead-only. The current stage, and while connected, the device, format and measured latency. See the status table.
ConnectionWi-Fi — enter the phone's IP or USB cable.
PhoneWi-Fi only. Pick a phone found on the network by name, or type its IP.
USB deviceUSB only. Auto (first available), or a specific device so the same phone always feeds this source.
Low latency modeRender the newest frame immediately instead of smoothing. On by default.
Hardware decoding (GPU)Decode on the GPU, falling back to software automatically. On by default.
Disconnect when this source isn't shown anywhereWhen the source is hidden — eye off, or in no visible scene, preview or projector — disconnect so the phone stops encoding. Saves battery and frees the phone for another source. Reconnects when shown. With auto-start on, it also stops and starts the phone's camera.
Start the phone's camera automatically when it's readyRemote start: when the app is open and idle, this source starts the camera by itself. On by default.
Start / Stop camera on the phoneButtons. Do it now, once.
Lip-sync audio sourceYour real microphone, the one to be aligned with the video.
Automatically delay that audio source…Applies the measured camera latency to that audio source.
Auto-calibrateMeasure the offset from the phone's mic reference instead of assuming it. Needs Auto lip-sync reference on in the app, and ignores the manual latency below.
Auto video delay for slow micsDelays the video instead, for microphones slower than the stream.
Audio device's own latencyManual mode only. Subtracted from the delay.

A LensLink Screen source has the connection, decoding and diagnostics properties only — there is no camera to control and no lip sync to measure.

Plugin settings (Tools → LensLink Settings)

Anything with one value for the whole plugin lives here, and is never duplicated in a source's properties.

SettingWhat it does
GPU decode pipeline (beta)Keeps decoded video on the graphics card instead of routing it through system memory. Applies to all LensLink sources after OBS restarts. Falls back per source automatically where textures cannot be shared. See Latency and performance.
Browser control panelServes the control panel on loopback. On by default.
Panel portDefault 9980.
Verbose diagnostics in the OBS logMuch more detail per connection. Turn on before reproducing a bug, off afterwards.
Dump received video to diskTroubleshooting only: writes the raw received stream so a decode problem can be reproduced off-device.
Record pipeline benchmarkLogs a summary every 5 seconds and writes one CSV sample per second into the plugin's config folder, for before/after comparisons.

App options

On the phone: the Options row at the bottom of the Setup screen.

OptionWhat it does
Remote start from OBSLets OBS start the camera while the app is open and idle. The phone stays awake while it waits; locking it or leaving the app ends standby.
Idle viewWhat the Live screen becomes 10 seconds after your last touch. Standard leaves the controls up. Clean feed hides everything but the picture. Dim screen blanks the screen, drops the brightness and shows the battery level — and is the only one that also dims remote-start standby, a minute in. Any tap brings the controls back.
Allow system video effectsExperimental. Lets iOS lower the capture frame rate on its own, which the Control Center video effects may require. Takes effect when the camera next starts.
Tally lightA pushed screen: the colors, the priority order, per-status off switches, and which statuses pulse. See below.
PresetsSaved camera looks, and the master switch for applying them. See Presets.
Send phone mic to OBSMakes this phone the camera source's audio in OBS — a wireless mic.
Auto lip-sync referenceSends the mic only as a timing reference for aligning your real microphone; it is never heard. Mutually exclusive with the option above.
Camera diagnosticsThe device's formats: which support the Control Center video effects, which are 10-bit HDR or Apple Log capable. Paste it into a bug report.
Check broadcast linkVerifies the screen-mirror extension is alive on the device, independent of OBS. Run it while a broadcast is active.

Tally light

The colored border around the Live screen. A user-ordered priority list decides what it shows: the highest status that is currently true and has a color lights the border, and setting a status to Off lets lower ones show through.

StatusDefaultMeaning
On airRed, 6 ptIn OBS's live output.
In previewAmber, 4 ptVisible in OBS, but not live.
Connection lostOffStreaming, but the link to OBS dropped.
Calibrating lip-syncOffMeasuring or re-measuring.
Lip-sync lockedOffCalibration locked on.
Low batteryOffLow Power Mode, or 20% and below, while unplugged.

Assignable colors are red, amber, green, blue, purple, white or off. On air keeps the heaviest stroke whatever its color, so live stays the most emphatic state. Any lit status can pulse instead of holding steady — off by default on every status, and iOS's Reduce Motion setting turns every pulse into a steady border of the same color: less motion, never less warning.

Where a setting is not

  • Resolution, frame rate, codec and color are on the phone, because only the phone knows what its cameras can do. The browser panel and the source properties can change them mid-stream, but the app owns the list.
  • Global switches are never repeated in source properties. If you cannot find something on a source, it is under Tools → LensLink Settings.
  • A control you can set from more than one place always reads the same cached state, so the app, the panel and the properties never disagree about what is currently true.
