Troubleshooting

Find your symptom below. Two things make almost any report solvable: the OBS log (Help → Log Files → View Current Log) and the app's Options → Camera diagnostics table.

The sources do not appear in OBS

  • Did you restart OBS? Plugins load once at startup.
  • Is OBS 32 or newer? Check Help → About.
  • Linux, log says libavcodec.so.60: cannot open shared object file: release tarballs up to v1.7.x linked the build machine's FFmpeg, so they only loaded on distros shipping that exact major version. Update to a current release, whose tarball bundles the decoder, or build from source — a local build links your own FFmpeg and always matches.
  • macOS, extracted from the zip: clear the download quarantine flag, or OBS silently refuses to load the plugin.

The source is called "iOS Camera", or updates do not seem to apply

An old pre-1.0 copy of the plugin (ios-camera-source.dll) is still installed and wins over the current one. The OBS log gives it away: "Source 'ios_camera_source' already exists".

Delete both of these from your OBS folder and restart:

obs-plugins\64bit\ios-camera-source.dll
data\obs-plugins\ios-camera-source\

The current installer removes it automatically.

USB device not found (Windows)

  • Install iTunes. It provides the Apple device driver the plugin needs. There is no way around this on Windows.
  • Tap Trust on the phone when prompted, with the phone unlocked.
  • Use a data cable. Charge-only cables carry no data, and nothing in the interface can tell you that.

If the status says "Device found, but the LensLink app isn't reachable", the cable and driver are fine — the app is not in the foreground, or the phone is locked.

The phone does not appear in the Phone dropdown

iOS requires the Local Network permission for the name broadcast. Allow it when the app asks, or turn it on in Settings → Privacy & Security → Local Network → LensLink. Typing the phone's IP address works regardless.

Also check that both devices are on the same network, and that it is not a guest network or one with client isolation enabled.

The app stops working after a week (sideloaded only)

Free Apple IDs expire sideloaded apps every 7 days. Re-install with Sideloadly to refresh it — your settings are kept — or switch to the TestFlight build, which does not have the problem.

"Hey Siri, start streaming with LensLink" is not recognized (sideloaded only)

Re-signing tools rewrite the app's bundle ID for free Apple IDs, which orphans the compiled Siri phrase data: Siri answers with a generic refusal even though the same action works from the Shortcuts app. Use the TestFlight build for working phrases, or drive it through a Shortcuts automation — lenslink://start works everywhere.

Also make sure the app has been launched at least once and that "Use with Siri" is on in Settings → Siri & Search → LensLink.

Control Center video effects are missing or greyed out

Portrait, Studio Light and the rest are iOS effects you toggle in Control Center while an app uses the camera — but iOS only offers them on certain cameras and capture formats, typically the front camera at moderate settings (nothing above 1920×1440). On many iPhones the rear cameras offer none at all, while newer hardware extends more effects to more cameras.

  • Options → Camera diagnostics shows exactly what your device offers, per camera and format.
  • LensLink already picks an effect-capable format whenever your resolution and frame-rate choice allows one.
  • If a toggle appears but greys out, drop the frame rate — effects can cap the capture rate — and turn on Options → Allow system video effects, which lets iOS vary it.
  • Versions before 1.8.1 never showed the panel at all: iOS only populates it for apps that declare each effect in their Info.plist, which LensLink now does.

Apple's Camera-app filters and Photographic Styles are not available to any third-party camera app. For creative looks, add filters to the source in OBS (right-click → Filters).

The screen broadcast will not connect

  • In the app, open Screen mirror tools → Check broadcast link while a broadcast is running. It verifies the extension is alive on the device, independent of OBS.
  • Sideloaded builds: re-signing can silently break the broadcast extension. TestFlight builds are unaffected.
  • Make sure the source in OBS is a LensLink Screen source. A Camera source fed a broadcast says so in its Status field.

No audio, or audio you cannot hear

  • Screen mirror, DRM apps are silent: iOS mutes DRM-protected audio (Apple Music, Spotify, Netflix) during any screen broadcast. Game, app and browser audio comes through fine.
  • You can record it but not hear it: set the source's Audio Monitoring to Monitor and Output in OBS's Advanced Audio Properties.
  • The phone's mic is not in OBS: turn on Send phone mic to OBS in the app's Options. If Auto lip-sync reference is on, it is off — one microphone has one role.

Two sources, one phone

A phone can feed one source at a time; a second source aimed at it reports that it is already in use. The exception: with Disconnect when this source isn't shown anywhere enabled, a hidden source releases the phone, so a Camera source in one scene and a Screen source in another can share it.

Latency spikes on Wi-Fi when zoomed in

Heavy digital zoom magnifies sensor noise, which is expensive to compress and produces bitrate spikes. Use the Telephoto lens for clean magnification, or switch to USB.

"Connected, but this OBS build can't decode the stream"

That build has no HEVC decoder. Switch the app's codec to H.264. Everything else works identically; the stream simply uses more bandwidth for the same picture.

The picture freezes or goes black when I switch apps on the phone

Expected. iOS suspends camera capture for apps that are not on screen, so the camera source blanks whenever LensLink is backgrounded or the phone is locked. A screen broadcast is the exception — it keeps running across apps by design.

Nothing here matches

Open an issue on GitHub and include:

  • The OBS log from the session (Help → Log Files → View Current Log). Turn on Verbose diagnostics in Tools → LensLink Settings first and reproduce the problem once.
  • The app's Options → Camera diagnostics table.
  • Device and iOS version, OBS version, plugin version (the app's version line is under the Setup screen's tail), and whether you are on Wi-Fi or USB.
