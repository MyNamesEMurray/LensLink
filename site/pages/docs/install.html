title: Install LensLink description: Install the LensLink plugin into OBS Studio on Windows, macOS or Linux, and the LensLink app on your iPhone or iPad through TestFlight, sideloading or Xcode. ---

Install

You need both halves: the plugin in OBS Studio, and the app on the phone. Install the plugin first — it is the half that needs OBS restarted.

Before you start

  • OBS Studio 32 or newer. Check Help → About. Older versions will not load the plugin at all.
  • iOS or iPadOS 15 or later on the phone or tablet.
  • For USB on Windows: iTunes, which supplies Apple's device driver. Wi-Fi does not need it. macOS and Linux need nothing extra.

Go to the download page

The plugin, on Windows

  1. Run the installer

    Download LensLink-installer-windows-x64.exe and run it. It finds your OBS Studio folder on its own and removes any pre-1.0 copy of the plugin it finds.

  2. Restart OBS Studio

    Plugins are loaded once at startup. Until you restart, the new sources will not be in the list.

  3. Check it loaded

    Sources → + should now offer LensLink Camera and LensLink Screen.

Prefer to do it by hand? Unzip lenslink-windows-x64.zip into C:\Program Files\obs-studio\, merging the obs-plugins and data folders with the ones already there.

The plugin, on macOS

  1. Open the package

    Download LensLink-installer-macos-universal.pkg. The package is not notarized, so the first time you must right-click → Open rather than double-click, then confirm at the Gatekeeper prompt.

  2. Restart OBS Studio

Prefer the zip? Extract lenslink-macos-universal.zip into ~/Library/Application Support/obs-studio/plugins/, then clear the download quarantine flag or OBS will refuse to load it:

xattr -dr com.apple.quarantine \
  ~/Library/Application\ Support/obs-studio/plugins/lenslink.plugin

The build is universal — it runs natively on both Apple silicon and Intel Macs.

The plugin, on Linux

Extract the tarball into your OBS plugin directory:

tar -xzf lenslink-linux-x86_64.tar.gz -C ~/.config/obs-studio/plugins/

Then restart OBS. If the plugin does not appear and the log mentions libavcodec.so.60: cannot open shared object file, you are on a release before 1.8 whose tarball linked the build machine's FFmpeg — update, or build from source, which links your own system's libraries.

Building the plugin from source

The full instructions are in obs-plugin/BUILDING.md. The short version on a Debian-family system:

sudo apt install cmake build-essential pkg-config \
     libobs-dev libavcodec-dev libavutil-dev qt6-base-dev

cd obs-plugin
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

qt6-base-dev is optional: it enables the OBS status-bar readout and the dockable LensLink panel. Everything else builds and runs without Qt.

The app on your iPhone or iPad

Three routes, in the order most people should prefer them.

TestFlight — recommended

Join the beta at testflight.apple.com/join/N7Rth6m3 and install from Apple's TestFlight app. Updates arrive automatically, Siri phrases work, and no computer is involved.

Sideloading the unsigned build

Download LensLink-unsigned.ipa from the latest release and install it with a tool such as Sideloadly and your Apple ID.

Two limits come from Apple, not from LensLink.

A free Apple ID expires sideloaded apps after 7 days — re-install to refresh it; your settings are kept.

Re-signing rewrites the app's bundle ID, which orphans the compiled Siri phrase data: "Hey Siri, start streaming with LensLink" gets a generic refusal even though the same action works from the Shortcuts app. Use lenslink://start in a Shortcut instead, or use TestFlight.

Building it in Xcode

No .xcodeproj is checked in; the project is generated by XcodeGen so the file list never conflicts in review. 

brew install xcodegen
cd ios-app && xcodegen generate && open LensLink.xcodeproj

Signing details and older-Xcode notes are in ios-app/BUILDING.md.

Updating

PluginRun the new installer over the old one, or replace the extracted files. Restart OBS.
App, TestFlightAutomatic, or from the TestFlight app's Update button.
App, sideloadedRe-install the new .ipa the same way you installed the first one.

The two halves negotiate a protocol version when they connect, so a slightly-older app and a newer plugin keep working. If a release ever requires both sides, its release notes say so.

Uninstalling

  • Windows: use the installer's uninstall entry, or delete obs-plugins\64bit\lenslink.dll and data\obs-plugins\lenslink\.
  • macOS: delete ~/Library/Application Support/obs-studio/plugins/lenslink.plugin.
  • Linux: delete the extracted files from ~/.config/obs-studio/plugins/.
  • App: remove it from the home screen as usual. Nothing is left on the computer.
