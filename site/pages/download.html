Before you install

The two things that trip people up.

OBS Studio 32 or newer Help → About. Older versions won't load the plugin.
A USB helper, for USB only Apple's device driver ships with iTunes. Linux needs the usbmuxd daemon instead; macOS has it built in. Wi-Fi needs none of them.
